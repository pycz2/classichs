# Neonfall (`packs/neon`)

Source of the cyberpunk pack "Neonfall": 3 champions, 60 collectible cards,
7 tokens, 3 starter decks, 8 languages, art, sounds and music. Design, balance
and the full card list: [DESIGN.md](DESIGN.md).

| Path | What |
|---|---|
| `DESIGN.md` | Setting, champions, mechanic names, effect spec, balance, card tables (generated), decks |
| `cards.json` | Every card (champions, powers and tokens included): stats, `keywords`/`refs` (engine ids), `effects` (machine-readable logic for the Lua scripts), `note` (value), `look` (art concept) |
| `locales/{en,ru,de,fr,es,pt_BR,it,pl}.json` | Pack name and description, classes, races, rarities, terms, mechanic names and tips, deck names, card names and texts (`$N` spell damage, `#N` healing) |
| `scripts/*.lua` | Card logic (docs/packs/api.md): one file per class, `neutral.lua`, `lib.lua` |
| `decks/*.json` | Starter decks: `zero_trace` (Iris Null), `redline_rush` (Mother Rust), `hostile_merger` (Director Vale) |
| `art/default/<id>.jpg` | One picture per card (512×512), `card_back` (512×768), `logo` (1280×720), `board` and `menu` (1920×1080) |
| `sounds/default/<event>.ogg` | The event sounds `game/sound.gd` plays (`play_card`, `attack`, `damage`, `spell`, `death`, `heal`, `turn_start`, `victory`, `defeat`, `click`, …) |
| `music/default/{menu,battle_1,battle_2}.ogg` | Synthwave loops |
| `ui/theme.json` | The interface look (docs/packs/format.md §11): dark glass panels, neon rims, glowing buttons, rain in the menu |
| `ui/fonts/` | Tektur (titles) and Exo 2 (text), SIL OFL 1.1 (licences beside them), subset to Latin, Latin Extended-A and Cyrillic with `pyftsubset` |

`cards.json` follows the field names of `docs/packs/cards.md` (`attack`,
`health`, `race`, `rarity`, `keywords`, `refs`, `mana_lock`, `spell_power`,
`unique`, `power`); `effects`, `target`, `combo_target`, `can_play`,
`options`, `note` and `look` are source-only: the pack build drops them. The
card logic is in `scripts/` (`ghost.lua`, `chrome.lua`, `exec.lua`,
`neutral.lua`, `lib.lua`); `cards.json` `script` fields point at it. Tests and
the balance simulation: `rust/engine/tests/neon.rs` (DESIGN.md §9).

## How it was made

- Design, card data and all translations: written by hand (Claude), checked by
  `python3 tools/neon_check.py` (references, keywords, the 8 locales — same
  numbers and markup as English — decks, art and sound files);
  `--design` regenerates the tables in DESIGN.md.
- Art: `python3 tools/neon_art.py` — the local Codex CLI image tool, 5 pictures
  per call, 3 calls at a time, one shared style prompt plus each card's `look`;
  cropped and scaled with `sips`, JPEG quality 80. Existing pictures are kept,
  so a rerun only redraws missing ones.
- Sounds and music: `python3 tools/neon_audio.py` — pure-Python synthesis on
  top of `tools/gen_audio.py` (oscillators, envelopes, reverb), deterministic,
  encoded to Ogg Vorbis with `ffmpeg`.

`packs/neon/.gdignore` keeps Godot from importing the source files; the game
reads the built `.cardpack`.
