Своя игра

Пак игры — всё, что превращает карточную игру в конкретную игру: правила, чемпионы, карты и что они делают, названия механик, тексты на всех языках, картинки, звуки, музыка, колоды, миссии и оформление. Движок Classic HS знает только нейтральные механики («существо, которое надо атаковать первым», «эффект при розыгрыше»); пак даёт им имена и наполняет содержимым.

Пак — это один файл .cardpack: zip-архив с фиксированной структурой. Вы пишете его как папку с обычными файлами, а tools/pack.py упаковывает её, проверяет и ставит хэши.

Целый пак в десяти файлах#

Tiny Duel — самый маленький пак, в который можно играть: Королева Солнца против Короля Луны, колоды по восемь карт, простое существо, существо с «Провокацией», боевой клич с целью, аура, предсмертный хрип и секрет. Ниже все файлы; вместе это игра, которую можно добавить в Classic HS и сыграть.

scripts/sun.lua (скрипты разобраны по шагам на странице Скрипты карт на Lua):

lualocal cards = {}

cards.sunbeam = {                       -- сила чемпиона: 1 урона
  target = "any",
  hero_power = function(g, me, t) g.damage(me, t, g.hp_dmg(me, 1)) end,
}

cards.archer = {                        -- Клич: 1 урона вражескому существу
  target = "enemy_minion",
  battlecry = function(g, me, t) g.damage(me, t, 1) end,
}

cards.banner = {                        -- другие ваши существа получают +1 к атаке
  aura = function(g, me)
    for _, m in ipairs(g.others(me)) do g.aura_add(m, 1, 0) end
  end,
}

return cards

scripts/moon.lua:

lualocal cards = {}

cards.moonlight = {                     -- сила чемпиона: восстановить 2 здоровья
  target = "any",
  hero_power = function(g, me, t) g.heal(me, t, g.heal_amt(me, 2)) end,
}

cards.moon_wolf = {                     -- Последнее слово: призвать Волчонка 1/1 на своё место
  deathrattle = function(g, me) g.summon(g.ctrl(me), "cub", g.died_pos(me)) end,
}

cards.ambush = {                        -- секрет: когда противник разыгрывает существо, 2 урона ему
  secret = {
    event = "after_summon",
    cond = function(g, me, ev) return ev.played and not g.mine(me, ev) end,
    effect = function(g, me, ev) g.damage(me, ev.entity, g.spell_dmg(me, 2)) end,
  },
}

return cards

scripts/neutral.lua:

lualocal cards = {}
cards.spark = { spell = function(g, me) g.add_mana(g.ctrl(me), 1) end }
return cards

Больше ничего в архиве быть не может. Часть пути — буквы, цифры, _, . и - (начинается с буквы, цифры или _), весь путь не длиннее 200 символов; ни скрытых файлов, ни ссылок, ни одного файла дважды.

rules.json#

Только целые числа. Необязательное поле получает значение движка по умолчанию (как в Classic).

РазделПоля
limitschampion_health (30), max_mana (10), hand (10: карта, взятая в полную руку, сгорает), board (7 существ на сторону), deck_size (30), copies (2), copies_by_rarity ({"LEGENDARY": 1}), queue_steps (5000: предохранитель)
startfirst_player ("random"), hand ([3, 4]: карты первого и второго игрока), coin (карта второму игроку или null), mulligan (true), first_player_draws (true)
bottrap (во сколько бот ценит свой секрет на столе; 0 — никогда не играет секреты, 2 — как в Neonfall), depth (2 — пробует и два действия подряд)
fatigueenabled, first, step: урон при взятии карты из пустой колоды
timersсекунды: turn (75), fuse (15), mulligan (45), grace (5), away (30)
default_powerКарта POWER для чемпиона без своей силы. Движку она нужна, даже если у всех чемпионов есть свои.
classes[{id, champion?, neutral?, playable?}]: класс с champion можно выбрать; карты класса с neutral идут в любую колоду.
racesРасы существ ("DRONE", "DAEMON").
rarities[{id, tier}], tier — одно из common, rare, epic, legendary (шансы Арены, рамки); no_rarity_tier — для карт без редкости.
setsВсе set, которые может назвать карта.
mechanicsВаше имя → {"engine": <id движка>} (ниже).
modes.constructedsets (карты этих наборов идут в колоды), class_cards ("own_and_neutral"), starter_rarities, starter_core (для стартовых колод)
modes.arenaДрафт Арены: sets, champions_offered, classes, picks, offer, tier_weights, special_picks, special_tier_weights, class_weight, neutral_weight, copies, wins, losses
rankedЛестница: start, ranks (звёзды за ранг, «полы», бонус за серию, эмблемы), streak, legend, season

Все поля со значениями Classic и точный алгоритм драфта: справочник rules.json.

Neonfall даёт второму игроку пять стартовых карт ("hand": [3, 5]): при [3, 4] первый игрок выигрывал 56–60 % партий ботов, при [3, 5] — 47–53 %. Прогоны баланса — в packs/neon/DESIGN.md §9.

Механики: слова движка и ваши#

Движок работает с нейтральными id; пак даёт имя каждому, который использует. Игроки видят только ваши имена (из mechanics в locales/<lang>.json). Для примера — имена Neonfall:

Id движкаЧто делаетNeonfall
GUARDВраги обязаны атаковать его первымFirewall
HASTEМожет атаковать сразуOverclock
BARRIERНе даёт пройти первому урону, потом исчезаетHardlight
DOUBLE_ATTACKДве атаки за ходDual-Core
STEALTHЕго нельзя атаковать и выбрать целью, пока он не атакуетCloak
SPELLPROOFЕго нельзя выбрать целью заклинаний и силEncrypted
SPELL_POWER+N к урону заклинаний (поле карты spell_power)Bandwidth
MANA_LOCKБлокирует N маны на следующий ход (поле карты mana_lock)Heat
TRAPСкрытое заклинание, срабатывающее на событиеProtocol
ON_PLAYЭффект при розыгрыше из рукиBoot
ON_DEATHЭффект при гибелиFlatline
COMBOБонус, если в этот ход перед ней уже сыграли картуChain
CHOICEВыбор одного из двух эффектовFork
WOUNDEDБонус, пока раненRedline
FREEZE, SILENCEМетки: карта замораживает / накладывает немоту (делает это её скрипт)Jam, Wipe

IMMUNE, CANT_ATTACK, AURA, TRIGGER, ADJACENT, теги состояния (FROZEN, EXHAUSTED, ARMOR, …) и остальное: весь словарь. В keywords карты — ваши имена; ключевые слова-теги (Guard, Haste, …) работают сами, а слова-хуки (On play, On death, …) только подписывают карту, у скрипта которой есть такой хук.

Массив карт; чемпионы, силы и токены — тоже карты.

Тексты: locales/<lang>.json#

Ключ
cards{id: {name, text}}. У каждой карты должно быть имя на основном языке.
mechanics{NAME: {name, tip}}: ключевое слово и его подсказка.
classes, races, rarities, sets{id: текст}
ranks{"25": …, "1": …, "0": "Легенда"}
decksНазвания колод.
missions, hintsВступления и реплики миссий, подсказки обучения.

Разметка текста карты: <b>…</b> и <i>…</i>; $N — число, которое растёт от силы заклинаний; #N — число, которое меняют модификаторы лечения; [x] в начале — переносы строк расставлены вручную. Нет текста — берётся основной язык, потом id.

Картинки, звуки, музыка, оформление#

  • Арты: art/<set>/<card id>.jpg (или .png, .webp), не больше 2 МиБ на картинку. У Neonfall два набора — default (живопись) и simple (плоский 2D); если картинки нет, берётся набор по умолчанию, потом нарисованная.
  • Звуки: по имени события — play_card, attack, damage, death, hero_power, turn_start, heal, armor, equip, secret, freeze, shield, spell, trigger, hit_big, draw, victory, defeat, click. Карта может назвать свои ("sounds": {"play": "…"}).
  • Музыка: music/<set>/menu.ogg, battle_1.ogg, battle_2.ogg, … (в матче — перемешанный плейлист).
  • Оформление: ui/theme.json перекрашивает весь интерфейс, пока ваша игра активна: цвета, стиль кнопок (wood, flat, neon), панели, шрифты (ui/fonts/*.ttf с лицензией), частицы в меню (embers, rain, none). Тёмное стекло и пурпурное свечение Neonfall — это его ui/theme.json; все ключи: UI theme.

Колоды и миссии#

Колода: {"name", "champion", "cards": [ids], "code"?, "arena"?}. pack.py check проверяет каждую по вашим правилам: размер, класс, копии по редкости, наборы, коллекционность.

Миссия (missions/<n>.json) — сценарная партия против босса. См. следующий раздел.

Обучение#

Что есть сейчас: миссии в паке. Пункт «Обучение» появляется в меню игры, если у активного пака есть файлы missions/; шесть миссий Classic (Дробитель, Миллхаус, Хранитель истории Чо, Король Мукла, Хемет, Иллидан) — такие файлы. В миссии:

ПолеСмысл
idНомер миссии, с 1.
champion, boss, boss_powerЧемпион игрока, босс (карта CHAMPION) и его сила.
powers_locked, boss_guardedСилами обоих пользоваться нельзя; босса нельзя атаковать, пока у него есть существа.
end_turn_block{while_can_play, while_can_attack}: игрок не может закончить ход, пока можно разыграть карту / атаковать существом.
player{mana, hand, deck}: начальная мана, рука, колода — верхняя карта первой.
boss_deckВерхняя карта первой.
mulliganfalse: без замены карт.
rewardКарта, которую показывают после победы.
hintsКлючи подсказок по порядку; тексты — в hints файла locales/<lang>.json.
scriptscripts/<file>.lua#<name>: хуки, которые чемпион игрока получает в начале, или null. В первых двух миссиях Classic — ench:tutorial_guard: здоровье чемпиона не падает ниже 1.

Слова миссии — вступление, реплики босса (start, hurt, defeat…), фраза о награде — в missions файла locales/<lang>.json. Миссии входят в rules_hash, их тексты — нет.

Сборка: tools/pack.py#

shpython3 tools/pack.py build <папка> -o <файл>.cardpack [--art-set mine=путь/к/картинкам]
python3 tools/pack.py check <файл>.cardpack     # все ошибки и предупреждения; код выхода 1 при ошибке
python3 tools/pack.py info  <файл>.cardpack     # размеры по папкам, число карт, языки, наборы, хэши
python3 tools/pack.py hash  <файл>.cardpack     # rules_hash и content_hash

build читает папку, выполняет её recipe.json, если он есть, пишет в манифест fx и rules_hash, проводит все проверки и записывает архив, только если ошибок нет. Архив детерминирован: одни и те же файлы дают побайтно одинаковый .cardpack.

Рецепты. Если пак собирается из данных, лежащих в другом месте, recipe.json перечисляет шаги сборки: {"root": "<папка>", "steps": [{"do": …}, …]}. Ни recipe.json, ни *.patch.json в пак не попадают.

ШагЧто делает
copyКопирует файлы из папки (from, to, маски files, except). Так Classic берёт свои арты и звуки.
sourceИсходник в собственной форме (Neonfall): убирает служебные поля карт (drop_card_fields), убирает файлы (drop_files), переносит файлы (move, например картинки в ui/), переносит pack.name/pack.description каждого языка в манифест, а terms — в ui.
hsjson, keywords, voice, translate, rank_namesШаги Classic: карты и тексты из данных HearthstoneJSON, имена механик, реплики, переводы, имена рангов.

--art-set id=папка добавляет ваш собственный набор картинок; он помечается local и никогда не передаётся другим.

Загрузка в игру#

  • На своём устройстве: Игры → Добавить файл игры (системный диалог выбора файла; в браузере — его выбор файла). Игра проверяет пак (пути, размеры, формат, rules_hash), хранит его как packs/<content_hash>.cardpack в папке пользователя и показывает в списке. Играть в эту игру делает его активным: колоды, арты, звуки, музыка и оформление переключаются сразу. Удалить убирает добавленный пак.
  • По сети с другом (коды): если у друга есть пак с тем же rules_hash, игра переключится на него; если нет и пак redistributable, другу предложат скачать его у вас.
  • На игровом сервере: игрок загружает пак в окне Игры сервера (Загрузить мою игру: до 10 паков по 100 МБ); админ загружает в админке или кладёт .cardpack в --packs-dir сервера. Сервер проверяет каждый новый пак: движок загружает правила, компилирует все скрипты и играет пробную партию с вашими первыми двумя готовыми колодами, перебирая все допустимые ходы; ошибка скрипта, сбой движка, зависшая партия или больше 20 секунд — и пак отклоняется.

Версии и хэши#

Что определяетМеняется, когда
versionНичего, это для людейВы её меняете
rules_hashИгру, как она играется. По нему подбирают соперников, его используют серверы и записи партий: два пака с одинаковым rules_hash — одна и та же игра.Меняются rules.json, cards.json (кроме fx, sounds, voice), missions/*.json или scripts/**/*.lua
content_hashФайл. Скачивания, кэши, копия в папке пользователя.Меняется любой файл

Поэтому можно исправить опечатку, перерисовать арт, добавить язык или набор звуков — и всё так же играть с друзьями, у которых старый файл: имена, тексты, картинки и манифест в rules_hash не входят. Поменяли число или скрипт — это другая игра. Оба хэша — SHA-256 по файлам (не по байтам архива), JSON в каноническом виде; точный рецепт: Hashes.
