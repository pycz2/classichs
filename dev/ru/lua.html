Скрипты карт на Lua

Карта с особым текстом получает поведение из небольшого скрипта на Lua. Движок Classic HS исполняет скрипты своим интерпретатором (rust/script) — одним и тем же на сервере, на компьютере и Android и в браузере, поэтому скрипт в одной и той же партии везде делает одно и то же. Язык — безопасное подмножество Lua 5.4: обычный Lua, только с целыми числами и без доступа к чему-либо за пределами игры.

Файл скрипта#

Файл в scripts/ выполняется один раз при загрузке пака и возвращает таблицу: id карты → хуки карты. Карта берёт набор хуков, если на него указывает cards.json: "script": "scripts/exec.lua#grid_overseer" (файл # ключ).

lua-- scripts/exec.lua (Neonfall)
local cards = {}

-- Grid Overseer: ваши Дроны получают +1 к атаке.
cards.grid_overseer = {
  aura = function(g, me)
    for _, m in ipairs(g.minions(g.ctrl(me))) do
      if g.race(m) == "DRONE" then
        g.aura_add(m, 1, 0)
      end
    end
  end,
}

return cards

Каждый хук получает g (библиотеку движка, API движка) и me — сущность, чей хук сработал (существо, заклинание, секрет, сила чемпиона). Сущности, игроки и числа — просто целые числа; id карт и названия механик — строки.

  • scripts/lib.lua (необязательный) загружается первым; таблица, которую он возвращает, видна во всех остальных файлах как глобальная lib: общие помощники.
  • На один ключ могут указывать несколько карт; ключи, которые не являются id карт, — это наборы хуков для зачарований ("ench:tutorial_guard").
  • У скриптов нет своего состояния. Локальные переменные на уровне файла — только для констант и вспомогательных функций: бот играет копии партии для просчёта на том же интерпретаторе. Состояние держите в игре — в тегах (g.set_tag), зачарованиях (g.enchant), характеристиках. После загрузки таблицы, которые вернул файл, доступны только для чтения.
  • Всё загружается или не загружается целиком: синтаксическая ошибка, неизвестная глобальная переменная, неизвестное имя хука (spel = …), карта, чей script никуда не ведёт, — пак отклоняется с указанием файла и строки.

Язык#

Значения и типы#

Тип
nilНичего. Отсутствующий ключ таблицы, не переданный аргумент.
booleantrue, false. Ложны только nil и false: 0 и "" — истина.
number64-битное целое. 42, 0x2A. Дробей нет: 1.5, 1e3 — ошибки.
stringБайты, неизменяемые; UTF-8 подходит. "двойные", 'одинарные', [[длинные]].
tableЕдинственная структура данных: массивы {1, 2, 3}, записи {x = 1}, словари {[key] = v}.
functionФункции и замыкания.

type(v) возвращает эти имена. Комментарии: -- до конца строки и --[[ длинный ]].

Переменные и видимость#

  • local x = 1, local a, b = f(). Локальная переменная видна до конца своего блока.
  • Своих глобальных переменных нет. x = 1 или function f() end на верхнем уровне — ошибка компиляции: assignment to undeclared global 'x' (declare it with 'local'). Пишите local x, local function f(). Присваивать полям можно: cards.X = {}, t.n = 1.
  • Глобальные имена — это стандартная библиотека и имена движка (g, lib, list); опечатка в них (ipars) — ошибка при загрузке пака, с файлом и строкой.
  • Замыкания видят окружающие локальные переменные; два замыкания, видящие одну переменную, делят её; у каждой итерации цикла свои копии переменных цикла.
  • _G и _ENV нет.

Операторы языка#

local, присваивание (a, b = b, a меняет местами), вызовы, do … end, if … then … elseif … else … end, while … do … end, repeat … until c (условие видит локальные переменные тела), числовой for i = a, b [, step] (целые; шаг 0 — ошибка), общий for k, v in pairs(t) / ipairs(t) / next, break, return (последним в блоке), function a.b.c() end, function a.b:m() end.

Операции#

От низшего приоритета к высшему: or, and, < > <= >= ~= ==, .. (склейка, в том числе чисел), + -, * // %, унарные not # -.

  • // — деление с округлением вниз: 7 // 2 == 3, -7 // 2 == -4. Знак % — как у делителя: -7 % 3 == 2.
  • + - * останавливаются с integer overflow in '+', если результат не помещается (стандартный Lua перескочил бы через край). Деление на ноль — ошибка.
  • Строки никогда не превращаются в числа: "10" + 1 — ошибка; используйте tonumber.
  • < сравнивает два числа или две строки; остальное — ошибка. == никогда не падает: таблицы и функции равны только самим себе.

Функции и таблицы#

  • Недостающие аргументы — nil, лишние отбрасываются. ... — переменное число аргументов, select("#", ...), несколько результатов — return a, b.
  • Методы: obj:m(x) — это obj.m(obj, x); у строк функции string есть как методы: s:sub(1, 3).
  • t.name — это t["name"]; присваивание nil удаляет ключ; #t — длина массива без дыр.
  • pairs обходит ключи в порядке добавления (стандартный Lua порядок не обещает). Изменение значения не двигает ключ; удалённый и добавленный заново ключ уходит в конец. Не добавляйте ключи во время обхода.

Стандартная библиотека#

Базовыеtype, tostring, tonumber(v [, base]), ipairs, pairs, next, select, error(v [, level]), assert, pcall
tableinsert, remove, sort (устойчивая), concat, unpack
stringlen, sub, upper, lower, rep, byte, char, format (только %d, %s, %%), find (только простой текст, без шаблонов)
mathmin, max, abs, clamp(x, lo, hi), floor, maxinteger, mininteger
listПомощники для массивов, никогда не меняющие аргумент: filter(t, f), map(t, f), count(t [, f]), any(t, f), all(t, f), sum(t [, f]), sort_by(t, key)

math.random нет: случайность берётся из игры (g.random, g.pick, g.random_alive, g.shuffle), чтобы оба игрока, сервер и записи партий совпадали.

ВозможностьЧто будет

Битовые & | ~ << >>Ошибка компиляции

Ограничения#

У каждого вызова хука свой бюджет; хуки, которые движок вызывает внутри него (урон, на который срабатывает другая карта), делят его.

ОграничениеПо умолчанию
Шаги (1 за оператор, итерацию цикла, вызов; встроенные функции — 1 за элемент)200 000
Глубина вызовов200
Записей в одной таблице10 000
Байт в одной строке64 КиБ
Памяти за один вызов16 МиБ

Обычный хук карты тратит от десятков до нескольких сотен шагов. pcall ловит ошибки скрипта, но не превышение ограничений.

Как работает скрипт карты#

ХукКогда срабатывает
targetНе функция: карте нужна цель. "any", "minion", "enemy_minion", "friendly_minion", "enemy_char", "friendly_char", "enemy_hero" или {base = …, filter = fn(g, me, t)}. Цель боевого клича существа необязательна (нет подходящей — разыгрывается без цели); цель заклинания обязательна.
battlecryСущество или оружие разыграно из руки: после того как существо встало на стол, до того как оружие экипировано. Не срабатывает, если его призвала другая карта.
spellЗаклинание сыграно (если его не отменил секрет).
comboВместо battlecry/spell, если в этот ход перед ней уже сыграли другую карту (Chain в Neonfall).
choose_one{"OPTION_A", "OPTION_B"}: две карты-варианта; игрок выбирает одну, и берутся её target и effect.
hero_powerИспользована сила чемпиона.
deathrattleПогибло (существо или оружие); g.died_pos(me) — где стояло.
on = {event = fn}Любое событие этого типа, пока me в игре. В очереди: выполняется после действия, которое его вызвало, по порядку.
now = {predamage = fn}Замена: срабатывает сразу внутри g.damage, до урона; меняйте ev.amount.
secretСекрет: {event, cond, effect}. На event в ход противника, если cond верно, секрет раскрывается и выполняется effect.
auraПересчитывается после каждого изменения, пока me в игре: вызывайте g.aura_add для того, что аура даёт сейчас. Когда me уходит, аура просто исчезает.
can_play, cost_mod, cost_auraВопросы только для чтения: можно ли сыграть карту сейчас, изменение её стоимости, стоимость других карт, пока эта в игре.

Все хуки с точными сигнатурами: API движка.

Детерминизм. Всё, что видит скрипт, задано скриптом и партией: только целые числа, pairs в порядке добавления, устойчивая сортировка, нет часов, нет своей случайности, tostring таблицы — счётчик, а не адрес. Поэтому партии двух игроков в сетевой игре идут в ногу, сервер может переиграть любую партию, а бот — копировать партию для просчёта.

Ошибки. Ошибка скрипта или превышение ограничения заканчивает партию ничьей («скрипт карты упал: …» с файлом и строкой), игра не падает. Хуки только для чтения не должны менять игру; вызов действия в них — ошибка.

Разобранные примеры#

Все из Neonfall (packs/neon/scripts/), если не сказано иное; сначала строка карты из cards.json, потом её хуки.

1. Простое существо: без скрипта#

Glasshound Runner, 2/2 с Hardlight и Cloak. Ключевые слова-теги работают сами:

json{"id": "glasshound_runner", "type": "MINION", "class": "NEUTRAL", "rarity": "COMMON", "set": "core",
 "collectible": true, "cost": 3, "attack": 2, "health": 2, "keywords": ["BARRIER", "STEALTH"]}

В Neonfall имена механик совпадают с id движка ("BARRIER": {"engine": "BARRIER"}); игроки видят Hardlight и Cloak из файлов локализации.

2. Боевой клич с целью#

Signal Jammer — Boot: заморозить (Jam) вражеское существо. target говорит, кого можно выбрать; боевой клич получает выбранного как t:

json{"id": "signal_jammer", "type": "MINION", "class": "NEUTRAL", "rarity": "COMMON", "set": "core", "collectible": true,
 "cost": 1, "attack": 0, "health": 3, "race": "DRONE", "keywords": ["ON_PLAY"], "refs": ["FREEZE"],
 "script": "scripts/neutral.lua#signal_jammer"}
luacards.signal_jammer = {
  target = "enemy_minion",
  battlecry = function(g, me, t) g.freeze(t) end,
}

Цель уже, с фильтром, — Field Auditor, Boot: дать дружественному Дрону Hardlight:

luacards.field_auditor = {
  target = {
    base = "friendly_minion",
    filter = function(g, me, t) return g.race(t) == "DRONE" end,
  },
  battlecry = function(g, me, t) g.give_tag(t, "BARRIER") end,
}

Если на столе нет дружественного Дрона, карта всё равно разыгрывается — без цели.

3. Аура#

Grid Overseer — Ваши Дроны получают +1 к атаке. Аура говорит, что даёт сейчас; движок забирает это, когда Overseer гибнет или Дрон уходит:

luacards.grid_overseer = {
  aura = function(g, me)
    for _, m in ipairs(g.minions(g.ctrl(me))) do
      if g.race(m) == "DRONE" then
        g.aura_add(m, 1, 0)
      end
    end
  end,
}

g.aura_add(m, atk, hp[, tags]) может давать и ключевые слова: g.aura_add(me, 0, 0, {DOUBLE_ATTACK = true}) — это Redline: Dual-Core из Neonfall (lib.redline).

4. Предсмертный хрип, который призывает#

Enforcement Mech — Firewall. Flatline: призвать двух Sentry Drone 0/2. Позиции считаются с нуля; два призыва в g.died_pos(me) ставят обоих туда, где стоял Mech:

luacards.enforcement_mech = {
  deathrattle = function(g, me)
    local p, pos = g.ctrl(me), g.died_pos(me)
    for _ = 1, 2 do
      g.summon(p, "sentry_drone", pos)
    end
  end,
}

g.summon возвращает новое существо или nil, если стол полон, — проверять не нужно: на полном столе просто призовётся меньше.

5. Секрет#

Protocol: Lockout — Когда противник разыгрывает существо, нанести ему 1 урона и заморозить. У карты ключевое слово TRAP, хук — secret:

luacards.lockout = {
  secret = {
    event = "after_summon",
    cond = function(g, me, ev) return ev.played == true and not g.mine(me, ev) end,
    effect = function(g, me, ev)
      g.damage(me, ev.entity, g.spell_dmg(me, 1))
      g.freeze(ev.entity)
    end,
  },
}

ev — таблица события (события): у after_summon есть entity, player, card и played (true, если существо пришло из руки, а не призвано другой картой). g.mine(me, ev) — «игрок события — мой владелец». g.spell_dmg добавляет силу заклинаний: секрет — тоже заклинание.

6. Хук на событие с помощником из lib.lua#

Medic Drone — В конце вашего хода восстановить 2 здоровья случайному раненому дружественному персонажу. lib.on_mine (из scripts/lib.lua Neonfall) строит хук on, срабатывающий только на события своего владельца:

lua-- scripts/lib.lua
function lib.on_mine(ty, f)
  return {
    on = {
      [ty] = function(g, me, ev)
        if g.mine(me, ev) then f(g, me, ev) end
      end,
    },
  }
end

-- scripts/exec.lua
cards.medic_drone = lib.on_mine("turn_end", function(g, me)
  local hurt = list.filter(g.chars(g.ctrl(me)), function(c) return g.dmg(c) > 0 end)
  local t = g.pick(hurt)
  if t then
    g.heal(me, t, g.heal_amt(me, 2))
  end
end)

g.pick делает случайный выбор генератором самой партии. В scripts/lib.lua Classic таких помощников больше (lib.hit(target, n, spell), lib.others_aura(atk, hp), lib.draw_battlecry(n)…).

7. Chain (серия приёмов) и Fork (выберите одно)#

lua-- Zero-Day: 1 урона существу и заморозить. Chain: 3 урона вместо 1.
local function zero_day(n)
  return function(g, me, t)
    g.damage(me, t, g.spell_dmg(me, n))
    g.freeze(t)
  end
end
cards.zero_day = { target = "minion", spell = zero_day(1), combo = zero_day(3) }

-- Executive Decision: Fork — Hard Reset (Wipe существа) или Retention Bonus (+2 здоровья и Firewall).
cards.executive_decision = { choose_one = { "hard_reset", "retention_bonus" } }
cards.hard_reset = { target = "minion", effect = function(g, me, t) g.silence(t) end }
cards.retention_bonus = {
  target = "minion",
  effect = function(g, me, t)
    g.buff(t, 0, 2)
    g.give_tag(t, "GUARD")
  end,
}

Два варианта — отдельные карты в cards.json (не коллекционные), со своими текстами в локализациях.

Отладка#

  • Пак не загружается. Движок называет файл и строку: scripts/moon.lua:3: assignment to undeclared global 'foo' (declare it with 'local'). Неизвестные глобальные имена, неизвестные хуки и скрипты, которые никуда не ведут, ловятся здесь, до того как сыграна хоть одна карта. Это сообщение покажут и tools/pack_try.gd, и Добавить файл игры в самой игре.
  • Карта падает в партии. Партия заканчивается ничьей с ошибкой и стеком вызовов: scripts/sun.lua:16: attempt to call a nil value (field 'damge') (scripts/sun.lua:16: in function 'battlecry').
  • Соберите позицию. Настройки → Инструменты отладки → Сцена (при активной вашей игре): положите мышью любые карты в руку, на стол, в колоду, в секреты и в слот оружия каждого игрока, задайте ману и здоровье и сыграйте против бота или за обе стороны. Сцена — это ещё и обычный JSON (кнопка JSON): скопируйте, поменяйте, примените снова.
  • Частые ошибки: 0 — истина (if g.room(p) then верно всегда; пишите g.room(p) > 0); позиции на столе считаются с нуля, а массивы — с единицы; поле, которого нет в событии, — nil (ev.target >= 0 падает на nil); until, end, and — ключевые слова ({["until"] = "use"}); / нет.

Ещё о проверке: Проверка и тесты. Язык во всех подробностях (экранирование, tostring, каждая функция библиотеки, подсчёт шагов): The Lua subset.
