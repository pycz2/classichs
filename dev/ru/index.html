Делайте карточные игры для Classic HS

Classic HS — движок для карточных игр в духе Hearthstone: два чемпиона, мана, которой каждый ход больше, существа на столе, заклинания, оружие, секреты. Сам движок знает только эти общие правила. Игра — её карты, что делает каждая карта, чемпионы, названия, арты, звуки, музыка, оформление и ранги — лежит в одном файле, паке игры (.cardpack). Classic 2014 — один такой пак; Neonfall, дождливый киберпанк с тремя чемпионами и 60 картами, — другой. Следующим может стать ваш.

Пак работает везде, где работает Classic HS: в браузере, на Windows, macOS, Linux и Android и на игровом сервере. Один и тот же пак с одними и теми же ходами даёт одну и ту же партию на любой из этих платформ.

Что понадобится#

  • Текстовый редактор. Пак — это JSON-файлы и короткие скрипты на Lua; ни компилятор, ни игровой движок ставить не нужно.
  • Python 3 для tools/pack.py (он собирает и проверяет пак; только стандартная библиотека). Он лежит в исходниках: git clone https://github.com/pycz2/classichs.
  • Сам Classic HS, чтобы сыграть в свою игру: хватит браузерной версии на этом сайте. Для быстрой проверки из командной строки (tools/pack_try.gd) нужны ещё Godot 4.7 и движок правил (см. Проверка и тесты).

Путь от идеи до игры#

  1. Опишите правила и карты. rules.json задаёт размер колоды, сколько карт помещается в руку, кто чемпионы; cards.json перечисляет все карты с их числами. Карте без особого текста больше ничего не нужно. → Своя игра
  2. Дайте особым картам скрипт. «При розыгрыше нанести 1 урона», «другие ваши существа получают +1 к атаке», «когда погибает — призвать Волчонка» — каждое из этого несколько строк на Lua поверх библиотеки движка g. → Скрипты карт на Lua, API движка
  3. Назовите всё на каждом языке. Названия и тексты карт, ваши собственные имена механик (в Neonfall «Провокация» называется Firewall, а «Боевой клич» — Boot), классы, колоды.
  4. Соберите и проверьте. tools/pack.py build делает .cardpack, отказывается собирать пак со сломанными ссылками и записывает хэши; tools/pack_try.gd играет вашу игру бот против бота и показывает любую ошибку скрипта с файлом и строкой. → Проверка и тесты
  5. Играйте. В игре: Игры → Добавить файл игры*. Поделитесь файлом с друзьями или загрузите его на игровой сервер.

Начните с примера#

ПримерЧто в нём есть
Tiny Duel (на странице Своя игра)Самая маленькая настоящая игра: два чемпиона, восемь карт, две колоды, три файла скриптов. Скопируйте и растите.
Neonfall (packs/neon в исходниках)Полная оригинальная игра: 73 карты, три стартовые колоды, восемь языков, свои арты, звуки, синтвейв-музыка и тема оформления (ui/theme.json). Все примеры скриптов на этих страницах — её карты.
Classic 2014 (packs/classic)534 карты, все механики Hearthstone Classic на Lua, шесть миссий обучения, рейтинговая лестница 2014 года. Её recipe.json собирает пак из данных, которые лежат в других местах репозитория.
