Card scripts: the engine API (g) and hooks

How a pack's Lua scripts talk to the engine (rust/engine, phase B of docs/superpowers/plans/2026-10-16-game-packs.md). The language itself (an integers-only, sandboxed Lua 5.4 subset, its limits and standard library) is in lua.md; the files of a pack in format.md.

Contents: script files · hooks · events · the g library · errors and limits · checking a pack against recorded games

Script files#

scripts/<file>.lua returns a table: key → hook set. A key is a card id or the name of an enchantment's hooks ("ench:nightmare").

lua-- scripts/mage.lua
local cards = {}

cards.VAN_CS2_029 = {                -- Fireball
  target = "any",
  spell = function(g, me, t)
    g.damage(me, t, g.spell_dmg(me, 6))
  end,
}

return cards
  • A card uses a hook set only if cards.json points at it: "script": "scripts/mage.lua#VAN_CS2_029" (file # key; several cards may point at one key). A card without script has no hooks.
  • A key that is not a card id is a named hook set for enchantments: g.enchant(m, {hooks = "ench:nightmare", player = p}) gives minion m the on/now/deathrattle hooks of ench:nightmare. Names are global: the same name in two files is a load error.
  • scripts/lib.lua (optional) is loaded first; the table it returns is the global lib in every other file (shared helpers). It is not a card file.
  • Files load once per pack, in path order. Top-level code runs at load time and must not touch the game (the g functions fail there).
  • Scripts keep no state of their own. Locals at the top of a file are fine for constants and helper functions, never for game state: the bot runs look-ahead copies of the game on the same interpreter, and the read-only hooks run on another one. Put state in the game: tags (g.set_tag), enchantments (g.enchant), stats. After loading, the tables a file returned (and the tables inside them, two levels deep) are read-only.

Everything about a pack loads or fails at once: a syntax error, an unknown global, an unknown hook name (spel = …), a card whose script points nowhere — load_pack returns the error and the pack is refused.

Hooks#

me is the entity whose hooks run (the card, the minion, the trap, the champion power), t the chosen target (nil when none), ev an event table. Return values are ignored unless said otherwise.

HookSignatureWhen
target"any" | {base = …, filter = fn(g, me, t) → bool, when = fn(g, me) → bool}The card (or power) needs a target. Bases: any, minion, enemy_minion, friendly_minion, enemy_char, friendly_char, enemy_hero (alias enemy_champion). Enemy STEALTH is never a target; SPELLPROOF blocks spells and powers. A minion's battlecry target is optional (no valid target: it is played without one); a spell's is required. filter is read-only. when (read-only): the spec applies only while it holds, else the card or power has no target (t is nil): Steady Shot with Steamwheedle Sniper.
battlecry (alias on_play)fn(g, me, t)A minion or weapon is played from the hand (after it is on the board / before it is equipped), or a hero card (a CHAMPION played from the hand: after it became its player's champion, with its Armor and power).
spellfn(g, me, t)A spell is cast (not if countered). A TASK card's (a Quest's) runs once it waits in the trap zone: it sets its goal (TASK_GOAL); its on hooks then count (TASK_PROGRESS) and fulfil it (g.remove, the reward to the hand).
combofn(g, me, t)Instead of battlecry/spell when another card was played before it this turn.
combo_targetlike targetThe target spec while combo is active (no target without combo).
choose_one (alias choice){"OPTION_A", "OPTION_B"}Two option cards; the player picks one (choice 0/1); the option card's target and effect are used.
effectfn(g, me, t)On a Choose One option card: what the option does (me is the played card).
hero_power (alias power)fn(g, me, t)On a POWER card: the power is used.
can_playfn(g, me) → boolThe card/power may be played now (read-only).
glowfn(g, me) → boolThe card in the hand glows yellow now: its condition holds ("if you're holding a Dragon", "if your deck has no duplicates"…; read-only, for clients: snapshots mark it glow, no rule reads it). Without it a card with a combo hook glows while its combo is on (g.combo(me)).
textfn(g, me) → string, …The values of the card text's {0}, {1}, … now (read-only, for clients: snapshots carry them as text_args; no rule reads them): a Jade card's next Golem ("4/4", and "n" for English's "a{1}" before 8, 11, 18), a made potion's two effects (a value that is a card id stands for that card's text in the player's language). Without it the client leaves the placeholders out.
deathrattle (alias on_death)fn(g, me)It died (minion or weapon; g.died_pos(me) is where).
on{<event type> = fn(g, me, ev)}Any event of that type while me is in play (or a trap). Queued: runs after the action that caused it.
hand{<event type> = fn(g, me, ev)}Like on, while the card is in its owner's hand (also an enchantment's hooks set's hand hooks: Shifter Zerus) (not during the mulligan; skipped if it left the hand before its turn in the queue): "when you draw this" (draw with ev.entity == me: Flame Leviathan, Burrowing Mine), "while this is in your hand" (Bolvar Fordragon). hand.discard also runs for the discarded card itself, which has left the hand: "when you discard this" (Fist of Jaraxxus).
now{predamage = fn(g, me, ev)}Replacement effects: runs at once, inside g.damage, before damage applies; set ev.amount to change it.
secret (alias trap){event = "<type>", cond = fn(g, me, ev) → bool, effect = fn(g, me, ev)}A trap: on event during the opponent's turn, if cond (omitted: always) holds, the trap is revealed, then effect runs.
aurafn(g, me)Recomputed after every change while me is in play: call g.aura_add for what it gives now.
aura_finalfn(g, me)Like aura, after every other aura (Lightspawn: attack = health).
cost_modfn(g, me) → intAdded to this card's cost (read-only).
cost_aurafn(g, me, card, cost) → intWhile me is in play: the new cost of any card (read-only; return cost to leave it).
on_choosefn(g, me, option, still)The player chose option of a g.request_choice (still: the offered ids still where they were).
immune_while_attackingtrueA weapon: its champion is IMMUNE while attacking with it.
durability_on_attackfn(g, w, defender) → boolA weapon: whether attacking costs durability (default yes).
cost_lasttrueIts own cost_mod comes after every other cost change instead of before them, in a pack with behaviour.cost_in_order (patch 9.2.0.21517 of 2017: Dragon's Breath, Solemn Vigil, Everyfin is Awesome and Obsidian Shard after Naga Sea Witch; 9.4: Crush; Kobolds & Catacombs).
bothfn(g, me, t)A Choose One card played with both options (BOTH_CHOICES, Fandral Staghelm: choice 2): this instead of the two options' effects in card order (Druid of the Claw's combined form; Keeper of the Grove silences first).
cost_firsttrue or a rank (1, 2, …)Its cost_aura comes before every other cost change in a pack with behaviour.cost_in_order (Summoning Portal); the lower rank first (true is 1; Knights of the Frozen Throne: Naga Sea Witch, Corpse Widow and Emerald Hive Queen 2, after Summoning Portal), then by when they came into play.

Read-only hooks (target.filter, can_play, glow, text, cost_mod, cost_aura) run while the engine only looks at the game (legal actions, costs in snapshots). Their g has only the query functions; calling an action there is an error. They must not depend on anything but the game.

An error in a read-only hook ends the game at the next action; in any other hook at once (see errors).

Events#

on, now and secret hooks get the event as a table: ev.type, and the fields of that type. Entity ids are numbers; "none" is -1 in events (not nil). A field that the event lacks is nil — compare carefully (ev.target >= 0 fails on nil).

Changing an event: assign to the table (ev.countered = true, ev.target = n, ev.amount = 0). When the hook returns, changed fields are copied back into the logged event, which the engine then reads (a countered spell does not run; a redirected spell hits the new target; predamage amounts replace the damage).

The g library#

g is passed to every hook and is read-only. Arguments: e, me, t, m are entity ids; p a player (0 or 1); card a card id; tag a mechanic name (the pack's name, e.g. Classic "TAUNT"; an engine id the pack renames, e.g. "GUARD", also works). Positions on the board are 0-based, left to right; nil means "the right end". A function that finds nothing returns nil. Numbers given to actions are clamped to ±1 000 000. Lists are Lua arrays (for _, m in ipairs(g.minions(p))), in the engine's order.

"power": the champion's power (a "use" mod goes when the power is used: Fencing Coach; Saboteur: turn = g.turn() + 1). lasting: it holds on any turn, kept until a card it applies to is played (with until = "use": "the next Dragon you play costs (2) less"). health = true`: the cards it applies to cost Health instead of Mana (paid as damage to the champion, Armor first; playable only while Health and Armor are more than the cost: Cho'gall).

g.remove(e[, zone])Takes e out of its hand/deck/board/trap list (and the weapon slot), optionally setting its zone.
g.cost(e)A card's cost now (cost hooks included).
g.random(lo, hi)A random integer lo..hi from the game's generator.
g.pick(list)A random item (or nil for an empty list).
g.random_alive(list)A random item that is in play and not dying, or nil.
g.shuffle(list)Shuffles the list in place (and returns it).
g.put_trap(e)Puts a trap card of its owner's hand or deck (or one made by g.create) into play, as if played but without the play event (logs trap_put); false (it stays where it is) when e is no trap there, the same trap is already in play or its owner has limits.secrets traps (Mad Scientist, Professor Putricide).
g.remove_dead()The death phase now: the dead leave the board (room for a summon) and their Deathrattles and death events are queued, to run after the hook (Mimiron's Head: V-07-TR-0N comes before the Mechs' Deathrattles).
g.resolve()Runs the queued triggers and the death phase now, inside the hook (Poison Seeds and Reincarnate: the destroyed minions die and their Deathrattles go before the Treants or the copy come).

Randomness must come from these (the game's seeded generator): every platform, the server and replays then agree.

Errors and limits#

  • A runtime error (error(...), a nil call, a bad argument: bad argument #2 to 'g.damage' (entity expected, got nil)) or a limit (200 000 steps per hook call, depth, memory; lua.md) ends the game as a draw: the engine logs {"type": "game_over", "winner": -1, "reason": "script_error", "error": "scripts/x.lua:12: …"}, and every API state reply then has script_error (the client shows "a card script failed: …").
  • Hooks the engine calls while running a hook (a damage triggers a now hook) share its step budget.
  • The engine never panics on a script; a pack that cannot load is refused by load_pack with the reason.

Checking a pack against recorded games#

Every Classic card hook is Lua (packs/classic/scripts/); the engine has no card logic of its own. The Classic pack is checked against the games recorded from the old GDScript engine (7833 games, rust/engine/README.md "Parity"):

shcd rust
# quick (~3 s): the committed 1731 games that mention a Warrior card
PARITY_BIG=0 PARITY_FILTER=WARRIOR cargo test -p classichs-engine --test parity -- --nocapture
# a few cards, all fixtures
PARITY_FILTER=VAN_EX1_398,VAN_EX1_407 cargo test -p classichs-engine --test parity -- --nocapture
# everything, 7833 games (~80 s)
cargo test -p classichs-engine -- --nocapture

PARITY_FILTER takes card ids, class names and lua (every card with hooks), comma-separated; a game is replayed if its recorded line mentions any of them. PARITY_BIG=0 skips fixtures/big. The first lines of a mismatch report show the step, the action and what differs. The Classic scripts are built into the engine (build.rs), so a test run always uses the current ones. builtin_rules_hash_matches_pack_py (tests/packs.rs) checks the built-in ruleset against tools/pack.py.

Pitfalls#

  • Same order, same randomness. Parity compares every event and the RNG state: a change to a Classic script must call g.pick/g.random/g.random_alive exactly where it did, as many times, on lists in the same order, and keep event order (damage before freeze…).
  • nil vs -1: queries and actions return nil for "none"; events keep -1. ev.field is nil when the event lacks it — nil >= 0 is an error.
  • 0 and "" are true in Lua: write g.room(p) > 0, #list > 0.
  • Positions are 0-based (g.summon(p, card, g.died_pos(me))), lists 1-based.
  • until, end, and, or, not are keywords: { ["until"] = "use" }.
  • No continue, no / (use //), no floats, no global variables.
  • Read-only hooks (target.filter, can_play, glow, text, cost_mod, cost_aura) see only queries: no g.cost, no actions.
  • g.tag adds aura values (SPELLPOWER from an aura counts); g.add_tag changes only the entity's own tag.
  • An on hook's changes to ev are written back; a copy of ev is not.
  • Do not keep game state in file-level locals (see script files).
  • In Classic, cards.patch.json and lib.lua are shared by every script file: add, do not reorder; prefer file-local helpers.
