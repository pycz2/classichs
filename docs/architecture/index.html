Classic HS: как устроена система

Godot 4.7.2 + Rust · версия 0.27.0 · состояние на 15.10.2026

Нажмите на блок схемы, чтобы прочитать о нём. Переключатель «Обзор / Подробнее / Всё» наверху добавляет файлы, классы и связи, а на уровне «Всё» ещё и пошаговые потоки со ссылками файл:строка.

В двух словах. Все правила игры живут в одном месте: в движке правил на Rust (rust/engine). Он детерминированный, принимает JSON-запрос (новая партия, ход, законные ходы, ход бота, снимок стола) и возвращает JSON-ответ. Этот же крейт работает везде: на игровом сервере как обычная зависимость, в настольных и Android-сборках как библиотека GDExtension, в браузере как WebAssembly. Godot стал тонким клиентом: через мост Rules он отправляет ходы, получает снимки и события и рисует их. Игровой слой (Match) решает, кто здесь главный: локальный движок (тренировка с ботом, обучение, отладка, игра по кодам) или сервер. Интерфейс собран кодом и проигрывает анимации по событиям. Онлайн работает двумя способами. По кодам без сервера: два браузера соединяются по WebRTC, у каждого своя копия партии в своём движке, после каждого хода они сверяют хэш (lockstep). Через необязательный игровой сервер на Rust (server/): сервер сам ведёт партию, проверяет каждый ход и присылает каждому игроку только то, что тот может видеть. Там же аккаунты, ранги, Арена, друзья и чаты.

  • Одни правила на всех. Движок на Rust заменил движок на GDScript (0.27) и ведёт себя точно как он: на 7833 записанных партиях те же события и тот же хэш состояния. Кода правил на GDScript больше нет.
  • Детерминизм. Генератор случайных чисел PCG32 как у Godot с seed партии, никаких float в логике, явный порядок обхода. Одинаковые seed и ходы всегда дают одинаковую партию, поэтому игре по кодам хватает пересылки ходов.
  • Одна сцена. ui/main.tscn содержит только корневой Control, все экраны — классы GDScript, которые ui/main.gd подменяет друг другом. Поверх экранов — оверлей друзей и чатов (Social).
  • Данные отдельно от кода. Карты, переводы, раскладки текста на картах, реплики и журнал изменений лежат в data/. Движок встраивает data/cards.json при сборке. Арт и звук сгенерированы скриптами из tools/.
  • Тесты на трёх уровнях. Правила — в Rust (rust/engine/tests: паритет со старым движком, API, виды игроков). Интерфейс и потоки — 354 теста Godot в 44 файлах tests/test_*.gd. Сервер — server/tests: полные партии ботами, проверка, что чужие карты не утекают, админка.
  • Сервер необязателен. Игра по кодам работает и без него. Сервер — отдельная программа classichs-server (Rust, tokio, axum, SeaORM, SQLite) с админкой в браузере. Партию ведёт он сам, поэтому изменённый клиент не может ни сделать незаконный ход, ни подсмотреть руку соперника.
  • Выпуск. Версия в project.godot, журнал на 8 языках, тег vX.Y.Z, сайт через tools/build_site.sh --publish в ветку gh-pages. GitHub Actions на каждый тег собирает движок под каждую платформу, игру под все платформы и сервер для Linux, Windows и macOS.
