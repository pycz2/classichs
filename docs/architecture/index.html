Архитектура переехала на сайт

Карта архитектуры теперь — часть страниц для разработчиков: блок-схема всей системы, каждый блок изнутри и пошаговые потоки со ссылками на строки кода.

  • На сайте: pycz2.github.io/classichs/dev/ru/architecture.html (по-английски — dev/en/architecture.html).
  • В локальной сборке сайта (tools/build_site.sh): build/site/dev/ru/architecture.html.
  • Исходники: содержимое — tools/arch_data.py, сборка и проверка ссылок — tools/arch_page.py (python3 tools/arch_page.py --check), просмотр — site/dev/arch.js.

The architecture map moved to the developer pages of the site: dev/en/architecture.html. Its content is tools/arch_data.py; tools/arch_page.py builds it and resolves every source reference to a line on GitHub.
