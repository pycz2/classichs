Classic HS: как устроена система

Godot 4.7.2 · версия 0.26.1 · состояние на 15.10.2026

Нажмите на блок схемы, чтобы прочитать о нём. Переключатель «Обзор / Подробнее / Всё» наверху добавляет файлы, классы и связи, а на уровне «Всё» ещё и пошаговые потоки со ссылками файл:строка.

В двух словах. Игра собрана как слоёный пирог. Внизу лежит детерминированный движок правил: он получает действие-словарь и возвращает список событий. Поведение карт описано словарями-хуками в cards/, а их числа и тексты взяты из data/cards.json. Над движком стоит игровой слой (Match): он решает, чей ход (человек, бот или соперник по сети), и рассылает события. Интерфейс целиком собран кодом: он по событиям проигрывает анимации и перестраивает стол по состоянию. Сеть работает двумя способами. Первый обходится без сервера: два браузера соединяются по WebRTC, коды подключения пересылаются через мессенджер. Второй идёт через необязательный игровой сервер на Rust (server/): там аккаунты, обычные и рейтинговые игры, Арена, друзья и сообщения. В обоих случаях обе стороны считают одну и ту же партию (lockstep) и после каждого хода сверяют хэш состояния. Сервер дополнительно проверяет каждый ход судьёй: это та же игра, запущенная без окна.

  • Детерминизм. Один RandomNumberGenerator с seed матча, никаких float в логике, явный порядок обхода. Одинаковые seed и действия всегда дают одинаковую игру, поэтому онлайну достаточно передавать одни ходы.
  • Одна сцена. ui/main.tscn содержит только корневой Control, все экраны — классы GDScript, которые ui/main.gd подменяет друг другом.
  • Данные отдельно от кода. Карты, переводы, раскладки текста на картах, реплики и журнал изменений лежат в data/. Арт и звук сгенерированы скриптами из tools/.
  • Всё проверяется тестами. Около 830 тестов в 70 файлах tests/test_*.gd: каждая карта, сеть, UI-потоки, случайные полные партии. У сервера свои тесты: cargo test в server/.
  • Сервер необязателен. Игра по кодам работает и без него. Сервер — отдельная программа classichs-server (Rust, axum, SQLite). Каждый ход он передаёт сопернику только после проверки судьёй, поэтому чужой изменённый клиент не может сделать незаконный ход.
  • Выпуск. Версия в project.godot, журнал на 8 языках, тег vX.Y.Z, сайт через tools/build_site.sh --publish в ветку gh-pages, релизные сборки под все платформы на каждый тег (GitHub Actions), там же собирается сервер для Linux, Windows и macOS.
