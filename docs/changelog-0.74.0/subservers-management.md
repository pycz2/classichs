## Русский

- Свой сервер по приглашению. Главный администратор делает приглашение администратора и отправляет ссылку. Кто по ней зарегистрируется или войдёт, получает свой сервер с адресом `/s/<имя>` и роль администратора на нём. Сколько серверов может держать один человек, решает главный администратор: первый даёт приглашение, остальные владелец заводит сам в пределах этого числа.
- Ограничения серверов: место под наборы, число наборов, игроков, ботов и турниров. Главный администратор задаёт общие значения и отдельные для любого сервера. Администратор сервера может их только понизить. Переполненный сервер не принимает новые наборы и новых игроков.
- Страница «Серверы» для главного администратора: состояние, владелец, игроки и сколько из них сейчас в сети, занятое место. Сервер можно приостановить, закрыть на время, открыть его панель или удалить (с подтверждением, запись остаётся в журнале). Игроков приостановленного сервера отключает, а при входе им объясняют причину.
- Общая библиотека наборов: главный администратор переносит набор из основного сервера в библиотеку, и его получают все серверы. У каждого сервера в списке библиотека и свои загрузки.

## English

- Your own server by invite. The super admin makes an admin invite and sends its link. Whoever registers or logs in with it gets a server of their own at `/s/<name>`, with the Admin role there. The super admin decides how many servers a person may own: the invite gives the first one, and the owner makes the rest himself up to that number.
- Server limits: pack storage, number of packs, players, bots and tournaments. The super admin sets the defaults and a value for any server; a server's admin may only lower them. A full server takes no new packs and no new players.
- A "Servers" page for the super admin: each server's state, owner, players and how many are online now, storage used. A server can be suspended, closed for a while, entered (its admin panel) or deleted (with a confirmation; the audit log keeps a record). Players of a suspended server are disconnected and told why when they try to log in.
- A common pack library: the super admin moves a pack of the main server into the library and every server offers it. Each server's list is the library plus its own uploads.
