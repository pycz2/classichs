## Русский

- В панели администратора появились роли: у каждой свой набор прав, а админ видит только те разделы и кнопки, на которые у него есть права. Есть готовые роли «Администратор», «Модератор» и «Наблюдатель», можно завести свои. Выдать роль можно только в пределах своих прав. Все изменения ролей пишутся в новый журнал аудита.

## English

- The admin panel has roles: each is a set of permissions, and an admin sees only the pages and buttons his permissions allow. There are built-in Admin, Moderator and Viewer roles, and you can make your own. You can only give the permissions you have yourself. Every role change goes into the new audit log.
