## Русский

- Чаты турниров: общий чат в списке турниров и свой чат у каждого турнира. Сообщения приходят сразу, у администраторов метка «админ», у создателя турнира в его чате метка «создатель». Модератор может удалить сообщение, и тогда все видят строку «удалено <имя>». Чат турнира открывается при создании турнира и через 10 минут после его конца становится только для чтения.
- В панели администратора появилась страница «Чаты»: можно читать чат списка и чаты турниров, писать от имени администратора и удалять сообщения. В настройках задаётся срок хранения чатов и личных сообщений: 14 дней по умолчанию, 0 значит хранить всегда. Сообщения старше срока сервер удаляет сам.

## English

- Tournament chats: a common chat in the tournaments list and a chat of each tournament's own. Messages arrive live; admins carry an "admin" mark and the tournament's creator a "creator" mark in its chat. A moderator can delete a message, and everyone then sees "deleted by <name>" in its place. A tournament's chat opens when the tournament is created and becomes read-only 10 minutes after it ends.
- The admin panel has a Chats page: read the list's chat and every tournament's, write as the admin, delete messages. The settings set how long chats and private messages are kept: 14 days by default, 0 keeps them forever. The server removes older messages by itself.
