## Русский

- Сервер готов принимать несколько игровых серверов по адресам вида `https://<сервер>/s/<имя>`. У каждого свои игроки, колоды, рейтинги, игры, турниры, чаты, повторы, статистика, боты и настройки, и данные одного сервера не видны на другом. Аккаунт один на все серверы. Всё, что было на сервере раньше, теперь относится к главному серверу по прежнему адресу, а прежние администраторы стали суперадминами.

## English

- The server is ready to host several game servers at addresses like `https://<host>/s/<name>`. Each has its own players, decks, ladders, games, tournaments, chats, replays, statistics, bots and settings, and no data of one shows on another. One account works on all of them. Everything the server had before now belongs to the main server at the old address, and the admins of before are super admins.
