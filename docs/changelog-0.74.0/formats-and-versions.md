## Русский

- Запись игры в Стандартном формате теперь воспроизводится в Стандарте: случайные карты (Раскопка и другие) берутся из тех же карт, что и в самой игре.

## English

- A replay of a Standard game now plays again in Standard: random cards (Discover and the like) come from the same cards as in the game itself.
