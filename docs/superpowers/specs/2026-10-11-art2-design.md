# Арт v2: уникальный и интересный рисунок для каждой карты

Дата: 2026-10-11
Статус: запрос владельца («арты поинтереснее, для каждой карты уникальные и не повторяться»); утверждено заранее («делать всё без лишних вопросов»)

## 1. Цель

У каждой из 534 карт (коллекционные, жетоны, герои, силы героев) — свой рисунок, не похожий на рисунки других карт, и рисунок рассказывает о карте: кто это или что делает заклинание.

## 2. Решения

| Вопрос | Решение |
|---|---|
| Способ | По-прежнему процедурный вектор (`ui/art.gd`), без файлов изображений. Рисунок — слои: сцена (фон), главный объект, знаки механик. |
| Сцена | 10 сцен (холмы, горы, лес, море, крепость, ночь, пещера, пустыня, облака, магические круги) с небом в цветах класса. |
| Существа-гуманоиды | Портрет по имени: раса (человек, гном, дворф, орк, тролль, эльф, таурен, нежить, огр, гоблин, пандарен, наг) → цвет кожи, уши, клыки, рога, борода; роль (маг, жрец, рыцарь, страж, король, пират, разбойник, шаман, воин, охотник, инженер) → головной убор и предмет в руке. |
| Звери | Вид по имени: ящер, волк, медведь, вепрь, кошка, птица, паук, змея, краб, черепаха, гиена, горилла, кодо, летучая мышь, рыба, лягушка, дракончик; иначе — общий силуэт зверя. |
| Заклинания и силы героев | Стихия (огонь, лёд, тайная магия, свет, тьма, природа, молния, яд, сталь) × форма по тексту карты: снаряд, удар по площади, усиление, защита, лечение, взятие карт, уничтожение, призыв, превращение. Размер и число частиц растут со стоимостью. |
| Оружие | Тип по имени (топор, меч, кинжал, молот, лук, глефа) × металл и камни. |
| Герои | Портрет героя класса (Джайна в шляпе мага, Гаррош — орк в рогатом шлеме, Утер — в золотом шлеме и т. д.) и эмблема класса. |
| Знаки механик | Провокация — щит за объектом, божественный щит — золотое кольцо, рывок — линии скорости, неистовство ветра — вихрь, маскировка — дымка, урон заклинаний — искры, заморозка — кристаллы, легендарная — корона и лучи. |
| Уникальность | У каждой карты «ключ рисунка» (объект и его вид, сцена, цвет акцента, отражение, размер, сдвиг). Ключи вычисляются для всех карт по порядку `dbfId`; при совпадении меняется вариант, пока ключ не станет уникальным. Тест: ключи и наборы фигур всех карт попарно различны. |
| Проверка глазами | `tools/art_sheet.gd` пишет `build/art_sheet.svg` — все рисунки на одном листе. |
