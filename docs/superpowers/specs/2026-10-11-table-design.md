# Подпроект 2: игровой стол, тренировка, отладочный стол, история ходов

Дата: 2026-10-11
Статус: утверждено владельцем заранее («делать всё без лишних вопросов»)

## 1. Цель

Сделать первый играбельный результат: человек открывает игру в браузере, выбирает класс и играет матч против бота. Отладочный стол позволяет собрать любую позицию и сыграть её. Во время матча можно открыть полную историю ходов.

## 2. Объём

Входит:

- Главное меню: «Тренировка», «Отладочный стол», «Выход». Пункты «Сетевая игра», «Обучение», «Коллекция» видны, но неактивны до своих подпроектов.
- Выбор тренировки: класс игрока и класс бота (9 героев). Колоды — базовые колоды классов (до подпроекта 3).
- Игровой стол 1280×720: герои, силы героев, оружие, столы, руки (рука соперника рубашкой вверх), секреты, мана, кнопка «Конец хода», mulligan, Choose One, выбор Tracking, конец игры.
- Управление мышью и касанием: клик по карте → (вариант) → (позиция) → (цель). Клик по своему персонажу → цель атаки. Клик по силе героя → (цель).
- Подсказка: при наведении на карту или существо показывается увеличенная карта с текстом.
- Простые анимации: всплывающие числа урона и лечения, вспышка у персонажа, исчезновение умерших. Тряска экрана при сильном уроне (≥ 5) — флаг `Match.shake_enabled`, настройка появится в подпроекте 6.
- Бот: жадный бот на один ход вперёд с оценкой позиции.
- Отладочный стол: редактор сценария (JSON), поиск карты по имени и кнопки «в руку/на стол/в колоду» для каждого игрока, режим «против бота» или «за обе стороны», кнопка «Позиция → JSON» в матче.
- Экран истории ходов: панель со всеми ходами с начала матча, без ограничения длины. Взятые соперником карты скрыты.
- `Cards.unload()` при выходе из игры.

Не входит (другие подпроекты): векторный арт карт (6), звук и TTS (6), перевод интерфейса (6), настройки (6), колоды игрока (3), сеть (4), обучение (5).

## 3. Решения

| Вопрос | Решение |
|---|---|
| Язык строк интерфейса | Английские исходные строки через `tr()`. Переводы (русский и другие) добавит подпроект 6. Имена и тексты карт берутся из `cards.json` на языке `TranslationServer.get_locale()`, с откатом на `enUS`. |
| Сцены | Минимум `.tscn`: одна главная сцена, остальной интерфейс строится в коде. Так меньше ручной вёрстки и проще тесты. |
| Рендер карт | `Control._draw()`: рамка цвета класса, кристалл стоимости, имя, текст, атака/здоровье. Место под арт — цветной блок с силуэтом-заглушкой; настоящий арт — подпроект 6. |
| Обновление стола | После каждого действия стол перерисовывается целиком из `GameState`; анимации строятся по списку событий `apply()`. |
| Бот | Для каждого законного действия: клон состояния → `apply` → оценка позиции. Берётся лучшее действие, если оно лучше «конца хода». Повтор, пока лучшее — не конец хода. |
| Клон состояния | `GameState.clone()` копирует сущности с теми же `id`, игроков, RNG (seed и state). История в клон не копируется. |
| Скрытая информация | Бот видит всё (тренировка). Стол показывает руку соперника рубашками. История скрывает чужие взятые карты. |
| Задержка хода бота | 0,6 с между действиями бота, чтобы человек видел ход. В тестах — 0. |

## 5. Оценка позиции (бот)

`value(g, p)` с точки зрения игрока `p`:

- Конец игры: победа +100000, поражение −100000, ничья 0.
- Для каждой стороны: `здоровье + броня` героя; для каждого существа `1,5·атака + здоровье + 1 (Taunt) + атака (Divine Shield)`; оружие `атака · прочность · 0,5`; карты в руке `1,5` за карту (только своя сторона).
- Итог: своя сторона минус сторона соперника.

Mulligan бота: заменить карты со стоимостью больше 3. Выбор (Tracking, Choose One): то же сравнение через клон.

## 6. Тесты

- `Decks`: 30 карт, только карты класса и нейтральные, не больше 2 копий.
- `CardText`: имя на русском и английском, числа подставлены, теги убраны.
- `GameState.clone()`: одно и то же действие на оригинале и клоне даёт одинаковый хэш; клон не меняет оригинал.
- `Bot`: выбирает летальную атаку; не возвращает незаконных действий; бот против бота доигрывает 20 матчей до конца без ошибок.
- `HistoryText`: показывает розыгрыш, атаку, Fatigue, сожжённую карту; скрывает карту, взятую соперником.
- `Match`: человек и бот по очереди; бот ходит сам; сигнал `finished` при конце игры.
- UI: сцена `ui/main.tscn` и стол собираются в headless-режиме без ошибок; матч бот против бота через `MatchView` проходит до конца. Визуальная проверка — снимок экрана web-сборки через headless Chrome.

## 7. Критерии готовности

1. Все тесты проходят.
2. Web-сборка открывается, меню работает, тренировка играется против бота до победы или поражения (проверка снимками экрана).
3. Отладочный стол загружает пример сценария и играет его.
4. История показывает все ходы матча.
