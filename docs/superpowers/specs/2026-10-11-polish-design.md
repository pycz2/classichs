# Подпроект 6: оформление — арт, звук, перевод, озвучка, настройки, журнал изменений

Дата: 2026-10-11
Статус: утверждено владельцем заранее («делать всё без лишних вопросов»)

## 1. Цель

Довести игру до законченного вида: узнаваемый векторный арт всех карт, музыка и звуки, интерфейс на нескольких языках, озвучка через встроенный в браузер синтез речи, экран настроек, полноэкранный режим, отключаемая тряска, окно журнала изменений по клику на версию.

## 2. Решения

| Вопрос | Решение |
|---|---|
| Языки интерфейса | 8: English, Русский, Deutsch, Français, Español, Português (BR), Italiano, Polski. Тексты карт уже есть на этих языках в `cards.json`. По умолчанию — язык системы, иначе английский. Китайский, японский и корейский не входят: стандартный шрифт Godot не содержит иероглифов, а в браузере нет запасного системного шрифта; шрифты CJK добавили бы к сборке несколько мегабайт. Их можно добавить позже вместе со шрифтами. |
| Формат переводов | `data/i18n/<locale>.json` — словарь «английская строка → перевод». Загрузка в `Translation` при старте (без шага импорта Godot, работает в тестах и в вебе). Отсутствующая строка показывается по-английски. Тест проверяет, что каждая строка `tr()` из кода есть в каждом файле. |
| Множественное число | Строки с числами переписаны так, чтобы обходиться без форм множественного числа («Cards in deck: %d / 30»). |
| Арт | Процедурный векторный арт, рисуется кодом (`draw_*`) и детерминирован по `id` карты: фон по классу, центральный мотив по типу и расе (Murloc, Beast, Dragon, Demon, Mech, Pirate, Totem), по школе заклинания (огонь, лёд, тайная магия, свет, тьма, природа) и по ключевым словам имени (Fireball → огненный шар, Polymorph → овца, Yeti → йети…). Свои эмблемы у 9 героев, у сил героев и у оружия. Без файлов изображений: игра остаётся лёгкой. |
| Звук | Звуки и музыка синтезируются заранее скриптом `tools/gen_audio.py` (чистый Python, без зависимостей) в небольшие WAV-файлы: розыгрыш карты, атака, урон, смерть, заклинание, сила героя, начало хода, победа, поражение, клик; две зацикленные мелодии (меню и бой). |
| Озвучка | `DisplayServer.tts_speak` (в вебе — Web Speech API) голосом выбранного языка: эмоции, реплики боссов обучения, имя легендарного существа или героя при выходе на стол (имя карты уже переведено на 14 языков). Выключается в настройках. |
| Настройки | `user://settings.json`: язык, громкость музыки, звуков и голоса, озвучка вкл/выкл, тряска экрана вкл/выкл, полноэкранный режим, имя игрока (`Profile`). Экран настроек доступен из меню и из матча. |
| Журнал изменений | Версия в углу меню; клик открывает окно с `CHANGELOG.md` (простое преобразование Markdown в BBCode, прокрутка). `CHANGELOG.md` входит в сборку. |
| Хвосты прошлых ревью | Строки хода в истории — по типу события, а не по тексту; панель истории не прыгает вниз, если игрок читает старые записи; переводимые причины рассинхронизации; имя по умолчанию переводится. |

## 3. Компоненты

| Файл | Назначение |
|---|---|
| `game/settings.gd` | `Settings`: загрузка, сохранение, применение (язык, громкость, тряска, полный экран). |
| `game/locale.gd` | Загрузка переводов, список языков. |
| `data/i18n/*.json` | Переводы. |
| `tools/i18n_strings.py` | Собирает все строки `tr()` из кода (для проверки и заготовок). |
| `ui/art.gd` | Процедурный арт карт, героев, сил героев. |
| `tools/gen_audio.py`, `audio/*.wav` | Синтез звуков и музыки. |
| `game/sound.gd` | Автозагрузка: музыка, звуки по событиям, озвучка. |
| `ui/settings_view.gd` | Экран настроек. |
| `ui/changelog_view.gd` | Окно журнала изменений. |

## 4. Тесты

- Каждая строка `tr()`/`translate()` из кода есть во всех 7 файлах переводов; переводы не пустые; плейсхолдеры `%s`/`%d` совпадают по количеству.
- Смена языка меняет строки интерфейса и имена карт.
- Настройки сохраняются и загружаются; битый файл не роняет игру.
- Арт: для каждой карты рисование проходит без ошибок; у разных карт разные мотивы там, где это задано.
- Звук: каждое событие стола находит свой звук; громкость 0 — тишина; озвучка вызывается с текстом на выбранном языке (через подменяемую функцию речи).
- Журнал изменений: версия в меню совпадает с `project.godot`; окно показывает содержимое `CHANGELOG.md`.
