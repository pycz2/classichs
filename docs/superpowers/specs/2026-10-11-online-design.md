# Подпроект 4: сетевая игра (P2P через WebRTC), эмоции, имя игрока

Дата: 2026-10-11
Статус: утверждено владельцем заранее («делать всё без лишних вопросов»)

## 1. Цель

Два человека в разных браузерах играют матч друг против друга. Своего сервера нет: браузеры соединяются напрямую через WebRTC, а служебные данные (signaling) игроки передают друг другу текстом через любой мессенджер. Во время матча доступны 6 эмоций, эмоции соперника можно заглушить. Соперник видит имя игрока.

## 2. Решения

| Вопрос | Решение |
|---|---|
| Транспорт | `WebRTCPeerConnection` + один надёжный упорядоченный `WebRTCDataChannel` («game»). В web-сборке Godot использует WebRTC браузера. В нативной сборке без плагина webrtc-native пункт «Сетевая игра» неактивен с подсказкой. |
| STUN | `stun:stun.l.google.com:19302`. TURN нет: в редких сетях (симметричный NAT) соединение не установится — экран подключения говорит об этом. |
| Signaling | Ручной, 3 шага: хозяин создаёт **код приглашения** → гость вставляет его и получает **код ответа** → хозяин вставляет код ответа. Код = base64(deflate(JSON `{"v", "type", "sdp", "ice": […]}`)). Кандидаты ICE собираются полностью до выдачи кода (одно сообщение на сторону). |
| Синхронизация | Lockstep из подпроекта 1: хозяин — игрок 0, гость — игрок 1. Хозяин выбирает seed; обе стороны создают одинаковый `Game` и применяют одни и те же действия. |
| Сообщения | JSON по каналу: `hello` (версия игры, хэш данных карт, имя, колода, герой), `start` (seed, обе колоды, имена — от хозяина), `action` (действие, номер, хэш состояния после него), `emote`, `bye`. |
| Проверки | Разные версия игры или данные карт — соединение закрывается с понятным сообщением. Чужое действие проверяется движком (`apply`); незаконное или с другим хэшем после применения — «рассинхронизация», матч останавливается. |
| Обрыв | Закрытие канала или потеря соединения — оверлей «Соединение потеряно», возврат в меню. |
| Скрытая информация | Lockstep требует, чтобы оба клиента знали обе колоды. Для игры с друзьями это допустимо; интерфейс показывает только то, что должен. |
| Эмоции | 6 базовых: Greetings, Well Played, Thanks, Wow, Oops, Threaten. Клик по своему герою открывает колесо эмоций; эмоция показывается пузырём у героя. Кнопка «заглушить» у героя соперника скрывает его эмоции. В тренировке эмоции тоже работают (бот не отвечает). Озвучка эмоций — подпроект 6. |
| Имя игрока | `Profile` в `user://profile.json` (имя, до 24 символов). Поле имени — на экране сетевой игры; экран настроек (подпроект 6) использует тот же `Profile`. Имя соперника показывается у его героя. |
| Тестируемость | Сетевая логика работает через интерфейс `Transport` (`send`, сигналы `received`, `closed`). В тестах — `LoopbackTransport` (пара в памяти). `WebRtcTransport` — тонкая обёртка. Для автоматической проверки в браузере web-сборка регистрирует отладочный объект `window.chs` (`host()`, `join(code)`, `finish(code)`, `state()`), которым headless Chrome соединяет две вкладки. |

## 3. Компоненты

| Файл | Назначение |
|---|---|
| `game/profile.gd` | `Profile.name`, `load()`, `save()`. |
| `net/transport.gd` | Базовый класс: `send(msg: Dictionary)`, сигналы `received(msg)`, `opened`, `closed(reason)`. |
| `net/loopback_transport.gd` | Пара транспортов в памяти (тесты). |
| `net/webrtc_transport.gd` | WebRTC: offer/answer, сбор ICE, канал «game», `poll()` в `_process`. |
| `net/signal_code.gd` | Упаковка и распаковка кодов приглашения и ответа. |
| `net/net_session.gd` | Протокол: hello → start → actions/emotes; проверки версии, хэша, законности; сигналы для UI. |
| `game/match.gd` | Поддержка удалённого игрока (`remote`): его ходы приходят из сети. |
| `ui/online_view.gd` | Экран сетевой игры: имя, колода, «Создать игру» / «Подключиться», поля кодов, состояние. |
| `ui/match_view.gd` | Имена у героев, колесо эмоций, пузыри, «заглушить», оверлей обрыва и рассинхронизации. |

## 4. Тесты

- `SignalCode`: упаковка и распаковка; мусор → ошибка.
- `NetSession` на `LoopbackTransport`: два клиента начинают одинаковую игру; действия одной стороны применяются у другой, хэши совпадают до конца матча (бот играет за обе стороны через сеть); несовпадение версии → закрытие с сообщением; незаконное действие от соперника → рассинхронизация; подменённый хэш → рассинхронизация; обрыв → сигнал; эмоции доходят; заглушённые эмоции не показываются.
- `Profile`: сохранение, обрезка длинного имени.
- UI: экран сетевой игры собирается; матч с удалённым игроком не даёт локальному игроку ходить за соперника.
- Web: две вкладки headless Chrome соединяются через `window.chs`, обе входят в матч, ход одной стороны виден другой.
