# Подпроект 7: лендинг на GitHub Pages и README

Дата: 2026-10-11
Статус: утверждено владельцем заранее («делать всё без лишних вопросов»)

## 1. Цель

Красивая интерактивная страница игры на GitHub Pages с анимациями и снимками экрана; игру можно запустить прямо на странице. В репозитории — `README.md` со снимками экрана.

## 2. Решения

| Вопрос | Решение |
|---|---|
| Адрес | `https://pycz2.github.io/classichs/` — лендинг; `…/play/` — web-сборка игры. |
| Публикация | Ветка `gh-pages` (только собранный сайт). `tools/build_site.sh` экспортирует web-сборку, собирает сайт в `build/site/` и публикует его в `gh-pages` через `git worktree`. Без GitHub Actions: шаблонам экспорта Godot нужна локальная установка. |
| Исходники страницы | `site/` в `main`: `index.html`, `style.css`, `main.js` — без фреймворков и сборщиков. |
| Языки страницы | Все 8 языков игры (en, ru, de, fr, es, pt_BR, it, pl; добавлено владельцем 2026-10-11): список языков; по умолчанию — язык браузера, иначе английский; выбор запоминается. Тексты — `site/i18n/<код>.js`; снимки экрана — только на английском (`media/screens/en/`), по решению владельца. |
| Анимации | CSS: парящие карты в шапке (арт из игры — снимки), появление секций при прокрутке (IntersectionObserver), наклон карт за курсором, галерея снимков с увеличением. Уважает `prefers-reduced-motion`. |
| Запуск игры | Секция «Играть»: игра грузится в `iframe` только по кнопке (страница остаётся лёгкой); ссылка на игру во весь экран. Сборка однопоточная — работает на GitHub Pages без особых заголовков. |
| Снимки экрана | Делаются автоматически из web-сборки (headless Chrome), лежат в `media/screens/` в `main`; их используют и README, и лендинг. |
| README | Что это, возможности, снимки, ссылка «Играть», как собрать и запустить тесты, устройство проекта, лицензия и отказ от связи с Blizzard. |
| Правовое | Имена и тексты карт — собственность Blizzard Entertainment; проект некоммерческий, фанатский, без логотипов и арта Blizzard (арт свой, процедурный). |

## 3. Проверка

- Страница открывается локально и с GitHub Pages без ошибок в консоли; переключатель языка; галерея; кнопка «Играть» загружает игру в `iframe`, меню игры появляется.
- Ширина 375 px: без горизонтальной прокрутки.
- README показывает снимки на GitHub.
