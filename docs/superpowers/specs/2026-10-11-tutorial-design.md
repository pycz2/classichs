# Подпроект 5: обучение

Дата: 2026-10-11
Статус: утверждено владельцем заранее («делать всё без лишних вопросов»)

## 1. Цель

Повторить обучение оригинальной игры: шесть миссий за Джайну против боссов с подсказками, которые по шагам объясняют правила. Обучение включается по желанию из меню и работает без сети.

## 2. Источник

Hearthstone Wiki, «Tutorial (removed)»: порядок миссий, здоровье боссов, особые правила, уроки, реплики. Точные колоды по миссиям вики не разбивает — колоды собраны заново из карт обучения (`TU4*`) и базовых карт мага так, чтобы каждая миссия учила своему уроку.

## 3. Миссии

| № | Босс (здоровье) | Урок | Особые правила |
|---|---|---|---|
| 1 | Hogger (10) | Розыгрыш существ, атака, мана, атака/здоровье | Рука пуста, порядок колоды задан, Джайна ходит первой, проиграть нельзя, нельзя закончить ход с неистраченной маной или атакой |
| 2 | Millhouse Manastorm (20) | Накопление маны, существа ценнее заклинаний, первое свойство (Raid Leader) | 2 карты на руке, проиграть нельзя, ограничения хода как в 1; босс играет только заклинания |
| 3 | Lorewalker Cho (25) | Размен существами, Battlecry, лечение | 2 карты на руке, можно проиграть; нельзя закончить ход с неиспользованной атакой |
| 4 | King Mukla (26) | Taunt, Charge, баффы, подсказка при наведении | Ограничений хода нет |
| 5 | Hemet Nesingwary (20) | Сила героя (Fireblast) | Силы героев открыты у обоих |
| 6 | Illidan Stormrage (30) | Оружие и прочность | Самый сильный босс |

Во всех миссиях: нет mulligan (руки заданы), сдаться можно, эмоции выключены, силы героев закрыты до миссии 5. После победы — экран награды (карта и реплика из вики). Прогресс (пройденные миссии) хранится в `user://progress.json`; следующая миссия открывается после победы, пройденные можно переиграть.

## 4. Решения

| Вопрос | Решение |
|---|---|
| Сборка матча | Через `Scenario`: колода в заданном порядке, рука, мана, герой и сила героя босса. Существующий механизм, без новых путей создания матча. |
| Закрытая сила героя | Тег `LOCKED` на силе героя: движок не предлагает её в законных действиях; стол её не показывает. |
| «Проиграть нельзя» | Чара `ench:tutorial_guard` на герое Джайны: урон не опускает здоровье ниже 1 (тот же механизм, что у Commanding Shout). |
| Ограничения хода | `MatchView.end_turn_check`: функция, которая может запретить конец хода и вернуть подсказку («Not yet! You have more cards to play!», «Not yet! You can still attack.»). |
| Подсказки | Список правил миссии: событие или состояние → текст. Подсказка показывается плашкой над столом, каждая один раз (кроме ошибок). Реплики босса — пузырь эмоции у героя босса (озвучка — подпроект 6). |
| Бот босса | Обычный бот подпроекта 2. Колоды боссов слабее колоды Джайны. |
| Карты обучения | Хуки для `TU4*`: Hogger SMASH!, Barrel Toss, Barrel (при смерти — Hidden Gnome), Stomp, Bananas, Will of Mukla, Shotgun Blast, Flames of Azzinoth, Flame Burst, Legacy of the Emperor, Transcendence (Cho нельзя атаковать и выбирать целью, пока у него есть существа), Crazy Monkey (кладёт Bananas в руку). |

## 5. Компоненты

| Файл | Назначение |
|---|---|
| `cards/tutorial.gd` | Хуки карт `TU4*`. |
| `engine/game.gd`, `engine/scenario.gd` | Тег `LOCKED` у силы героя; поле сценария `hero_power_locked`. |
| `game/missions.gd` | Описания 6 миссий: герои, колоды, руки, правила, подсказки, реплики, награды. |
| `game/progress.gd` | Прогресс обучения. |
| `game/tutorial.gd` | Контроллер миссии: сборка матча, подсказки по событиям, проверка конца хода. |
| `ui/tutorial_view.gd` | Выбор миссии; экран награды. |
| `ui/match_view.gd` | Плашка подсказки, `end_turn_check`, скрытие закрытой силы героя. |

## 6. Тесты

- Хуки всех карт `TU4*`.
- `LOCKED`: сила героя не в законных действиях; сценарий с `hero_power_locked`.
- Каждая миссия собирается без ошибок; у Джайны и босса правильные герои, здоровье, рука, порядок колоды.
- Миссии 1–2: Джайна не падает ниже 1 здоровья.
- Ограничения хода: конец хода запрещён с неистраченной маной (миссии 1–2) и с атакой (1–3), разрешён без них.
- Подсказки: первая подсказка показывается при старте, подсказка об атаке — когда атака возможна.
- Бот проходит каждую миссию за Джайну до победы (миссии проходимы).
- Прогресс: победа открывает следующую миссию и сохраняется.
