# Оформление — план реализации

**Spec:** `docs/superpowers/specs/2026-10-11-polish-design.md`
**Исполнение:** inline (Native), один финальный ревьюер. Владелец заранее утвердил план.

## Global Constraints

- Godot 4.7.2, GDScript; никаких новых зависимостей и файлов изображений.
- Все строки интерфейса — английские ключи через `tr()`; переводы в `data/i18n/<locale>.json`.
- Аудиофайлы генерирует `tools/gen_audio.py` (чистый Python), они коммитятся.
- `CHANGELOG.md`; в конце версия `0.6.0`.

## Review Focus

1. Смена языка в настройках: весь интерфейс и имена/тексты карт на новом языке без перезапуска; строки без перевода — по-английски, а не пустые.
2. Громкость 0 и выключенная озвучка — полная тишина; браузер без голосов для языка — без ошибок.
3. Битый `settings.json` — игра запускается с настройками по умолчанию.
4. Полноэкранный режим в браузере включается только по действию пользователя (кнопка), без ошибок.
5. Арт рисуется для каждой карты без ошибок и не тормозит при большом количестве карт на экране.

## Задачи

1. **`Locale` + `Settings`**: загрузка переводов, язык по умолчанию, сохранение и применение настроек; инструмент сбора строк; тест покрытия переводов (пока только английский).
2. **Переводы**: 7 языков для всех строк интерфейса.
3. **Экран настроек**: язык, громкости, озвучка, тряска, полный экран, имя; из меню и из матча.
4. **Журнал изменений**: версия в меню, окно с `CHANGELOG.md`.
5. **Звук**: `gen_audio.py`, `Sound` (музыка, звуки событий, громкости), озвучка через TTS.
6. **Арт**: процедурный векторный арт карт, героев, сил героев.
7. **Хвосты ревью**: строки хода в истории по событию, прокрутка истории, переводимые причины, имя по умолчанию, строки без множественного числа.
7a. **Дектрекер** (добавлено владельцем): панель в матче — своя колода, оставшиеся карты с шансом взять, сыгранное соперником; каждый вид скрывается, выбор сохраняется.
7b. **Таймер-фитиль** (добавлено владельцем): только в сетевой игре; 75 секунд на ход, фитиль последние 15 секунд; по истечении клиент активного игрока сам заканчивает ход (выбор — первый вариант, mulligan — оставить).
8. **Проверка**: снимки экрана на нескольких языках, web-сборка, `CHANGELOG`, версия `0.6.0`.

## Журнал решений

- Языки: 8 вместо 12 (нет шрифтов CJK в стандартном шрифте Godot; в браузере нет запасного шрифта).
- Задача 2. Решение: 7 файлов переводов написали параллельные агенты по готовому русскому образцу; проверка — тест покрытия (ключи, непустые значения, плейсхолдеры) и выборочное чтение. Термины — официальные термины Hearthstone на каждом языке. Цена ошибки: неточные формулировки, правка по одной строке.
- Задача 3. Решение: смена языка в матче заново ставит тексты фиксированных кнопок (`MatchView.LABELS`) и перерисовывает стол; уже записанные строки истории остаются на старом языке. Цена ошибки: смешанные языки в истории до конца матча.
- Задача 3. Решение: флажок «Полный экран» показывает реальный режим окна (в браузере Esc выходит из полного экрана без нас); на десктопе сохранённый режим включается при старте, в браузере — только по клику. Найдена и исправлена ошибка: кнопка «Сдаться» не становилась «Меню» после конца игры (нерекурсивный `find_child`).
- Задача 5. Решение: озвучка — имена легендарных существ и новых героев при выходе на стол, эмоции и реплики боссов; при старте матча голос молчит. Музыка зациклена по сигналу `finished` (возможна короткая пауза на стыке). Без узла `Sound` все вызовы молчат — тесты и инструменты без звука. Цена ошибки: мало или много голоса; правка списка событий.
- Задача 6. Решение: поля `spellSchool` в данных нет, поэтому мотив выбирается по началу слова в английском имени (таблица `Art.KEYWORDS`), затем по расе, затем по типу и классу. Фигуры — данные, тест проверяет каждую карту (фигуры внутри рамки, ≥25 разных мотивов). Цена ошибки: у отдельных карт неточный мотив; правка одной строки таблицы.
- Задача 7a. Решение: дектрекер — наложение справа (760, 20), его можно держать открытым вместе с историей; кнопка «Конец хода» остаётся видна. Исходная колода хранится в `Game.start_decks`; у позиций из отладочного стола исходной колоды нет — показывается текущая. Шанс — копий / карт в колоде (следующее взятие). Цена ошибки: панель закрывает часть стола справа, пока открыта.
- Задача 7b. Решение: на mulligan — 45 секунд; ход по таймеру отправляет только клиент активного игрока обычным ходом, поэтому lockstep не ломается. Если клиент соперника завис, таймер его не заменяет: это обрабатывает обрыв соединения. Цена ошибки: зависший соперник держит ход до обрыва.

### Финальное ревью (Opus)

- Критических нет. Исправлено: история после открытия не следила за новыми ходами — `test_hidden_history_follows_new_moves` RED→GREEN; смена языка в матче не меняла заголовки дектрекера, заголовок истории, имя бота и открытые окна — `test_match_settings_relabels_static_buttons` RED→GREEN; тесты после `*.path = DEFAULT_PATH` читали реальные файлы игрока (повышено до Important: прямое требование владельца) — раннер ставит тестовые пути перед каждым тестом, `test_zz_isolation` RED→GREEN. Набор 643/643.
- Решение: при смене языка в матче открытое окно (mulligan, выбор, конец игры) строится заново; отмеченные для замены карты mulligan и окно подтверждения сдачи сбрасываются. Цена ошибки: игрок отмечает карты заново.
- Отложено (minor): «Ваша колода» затемняет строку, только когда взяты все копии; секрет, украденный Kezan Mystic, показывается как «?»; искра фитиля мигает, пока ждём mulligan соперника; `data/i18n/keys.json` попадает в web-сборку; RegEx в `Art.motif` компилируется при каждом вызове; голос pt_BR может быть европейским; «заглушить» не обрывает уже начатую речь соперника.
