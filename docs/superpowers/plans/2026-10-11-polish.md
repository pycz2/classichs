# Оформление — план реализации

**Spec:** `docs/superpowers/specs/2026-10-11-polish-design.md`
**Исполнение:** inline (Native), один финальный ревьюер. Владелец заранее утвердил план.

## Global Constraints

- Godot 4.7.2, GDScript; никаких новых зависимостей и файлов изображений.
- Все строки интерфейса — английские ключи через `tr()`; переводы в `data/i18n/<locale>.json`.
- Аудиофайлы генерирует `tools/gen_audio.py` (чистый Python), они коммитятся.
- `CHANGELOG.md`; в конце версия `0.6.0`.

## Review Focus

1. Смена языка в настройках: весь интерфейс и имена/тексты карт на новом языке без перезапуска; строки без перевода — по-английски, а не пустые.
2. Громкость 0 и выключенная озвучка — полная тишина; браузер без голосов для языка — без ошибок.
3. Битый `settings.json` — игра запускается с настройками по умолчанию.
4. Полноэкранный режим в браузере включается только по действию пользователя (кнопка), без ошибок.
5. Арт рисуется для каждой карты без ошибок и не тормозит при большом количестве карт на экране.

## Задачи

1. **`Locale` + `Settings`**: загрузка переводов, язык по умолчанию, сохранение и применение настроек; инструмент сбора строк; тест покрытия переводов (пока только английский).
2. **Переводы**: 7 языков для всех строк интерфейса.
3. **Экран настроек**: язык, громкости, озвучка, тряска, полный экран, имя; из меню и из матча.
4. **Журнал изменений**: версия в меню, окно с `CHANGELOG.md`.
5. **Звук**: `gen_audio.py`, `Sound` (музыка, звуки событий, громкости), озвучка через TTS.
6. **Арт**: процедурный векторный арт карт, героев, сил героев.
7. **Хвосты ревью**: строки хода в истории по событию, прокрутка истории, переводимые причины, имя по умолчанию, строки без множественного числа.
8. **Проверка**: снимки экрана на нескольких языках, web-сборка, `CHANGELOG`, версия `0.6.0`.

## Журнал решений

- Языки: 8 вместо 12 (нет шрифтов CJK в стандартном шрифте Godot; в браузере нет запасного шрифта).
