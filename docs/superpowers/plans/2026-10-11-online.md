# Сетевая игра — план реализации

**Spec:** `docs/superpowers/specs/2026-10-11-online-design.md`
**Исполнение:** inline (Native), один финальный ревьюер. Владелец заранее утвердил план.

## Global Constraints

- Godot 4.7.2, GDScript; строки интерфейса через `tr()`.
- WebRTC только в web-сборке; нативная сборка показывает пункт «Сетевая игра» неактивным.
- Вся сетевая логика тестируется через `LoopbackTransport`, который передаёт сообщения через JSON (как настоящая сеть: числа приходят как `float`).
- `CHANGELOG.md`; в конце версия `0.4.0`.

## Review Focus

1. Соперник присылает действие за чужого игрока, с неверным номером, после конца игры или мусор вместо JSON: матч не ломается, локальный игрок видит понятную причину.
2. Обрыв в любой момент (до старта, во время mulligan, во время хода бота нет — только люди): оверлей «Соединение потеряно», возврат в меню без зависших таймеров.
3. Разные версии игры или данных карт: соединение закрывается с сообщением до начала матча.
4. Неверный или чужой код приглашения/ответа: сообщение, а не сбой.
5. Спам эмоциями и заглушение: заглушённые эмоции не показываются, интерфейс не забивается.

## Задачи

1. **`Profile`** — имя игрока (до 24 символов), `user://profile.json`. Тесты.
2. **`SignalCode`** — упаковка/распаковка кодов. Тесты.
3. **`Transport` + `LoopbackTransport`**. Тесты.
4. **`Match` с удалённым игроком** + **`NetSession`** (hello/start/action/emote/bye, проверки). Тесты: полный матч бот против бота через сеть, рассинхронизация, чужое действие, версии, обрыв, эмоции.
5. **`WebRtcTransport`** + отладочный `window.chs` в web-сборке.
6. **`OnlineView`** + пункт меню (только web). Тесты на loopback.
7. **Стол:** имена у героев, колесо эмоций, пузыри, «заглушить», оверлеи обрыва и рассинхронизации. Тесты.
8. **Web-проверка:** две вкладки headless Chrome соединяются и играют; `CHANGELOG`, версия `0.4.0`.
