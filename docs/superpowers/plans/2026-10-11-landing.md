# Лендинг и README — план

**Spec:** docs/superpowers/specs/2026-10-11-landing-design.md

## Задачи

1. **Снимки экрана**: сценарий headless Chrome, снимки меню, матча, дектрекера, коллекции, обучения, сетевой игры, отладочного стола, настроек; `media/screens/*.png`.
2. **Страница**: `site/index.html`, `style.css`, `main.js` — шапка с анимацией, возможности, галерея, «Играть» (iframe по кнопке), RU/EN, адаптивность.
3. **Сборка и публикация**: `tools/build_site.sh` → `build/site/` → ветка `gh-pages`; проверка страницы с GitHub Pages.
4. **README.md** со снимками и ссылками.
5. **Проверка**: локально и на Pages, консоль без ошибок, ширина 375 px; CHANGELOG, версия `0.7.0`; ревью; merge; push.

## Журнал решений
- Задача 1. Решение: снимки делаются из web-сборки сценарием headless Chrome; для снимка матча пример отладочного стола стал витринной позицией (тест проверяет, что он собирается). Найдены и исправлены символы, которых нет в шрифте (тест `test_font_has_every_character_the_interface_uses`).
- Задача 3. Решение: публикация через ветку `gh-pages` без GitHub Actions — шаблоны экспорта Godot стоят локально. Цена ошибки: сайт обновляется только запуском `tools/build_site.sh --publish`.

### Финальное ревью (Opus)

- Критических нет. Исправлено: при заблокированном `localStorage` страница оставалась пустой — воспроизведено в headless Chrome (SecurityError, текст скрыт) → чтение в try/catch, `.reveal` скрывается только при `html.js`; после неудачной первой публикации следующие падали («branch gh-pages already exists») — воспроизведено во временном репозитории → удаление оставшейся локальной ветки, отличие «нет ветки» (код 2) от сетевой ошибки; повторная публикация проверена; `build/.gdignore` создаётся перед экспортом (повышено до Important: иначе Godot упакует файлы из `build/` в сборку игры).
- Отложено (minor): нет проверки незакоммиченных изменений перед публикацией; значки существ при трёх сразу заходят под кружки атаки и здоровья; тест шрифта не проверяет `cards.json` (в pt_BR тексте VAN_EX1_607 есть U+2011, показывается квадратом); галерея: миниатюры и увеличение не доступны с клавиатуры, у вкладок нет стрелок и `aria-controls`; на экране 320 px заголовок обрезается; фон блока «Играть» всегда английский.
