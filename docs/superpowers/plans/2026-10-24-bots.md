# Classic bots for the game server — plan

> **0.29:** the bots moved into the game server (`server/src/bots`, the admin's Bots page, three levels,
> two adapters: in-process and network); the separate `bots/` program below is gone. See server/README.md "Bots".

**Goal:** one local Rust process (`bots/`, binary `classichs-bots`) runs N bots that play Classic on the
owner's server (`wss://hs.borovilov.xyz`) to give it life: 6 ladder bots (ranked, then casual, then
ranked…; a random deck of their class library each game) and 3 Arena bots (start a run, pick a hero,
draft 30 cards, play until the run ends, start again). A random 5–15 s pause before every game. A local
admin page without login (127.0.0.1) shows every bot: status, opponent, the board as the bot sees it,
its last decision, records, errors and logs.

**Not the game client:** bots speak the server's WebSocket JSON protocol (server/README.md "Protocol
summary"); the rules engine (`rust/engine`) is a library for thinking.

## Fair play: only what a player knows

The server sends each player its own `view` (opponent's hand and secrets hidden, no decks, no RNG).
`view::from_snapshot_in` makes a playable game of it (hidden cards = a filler). The bot never sees more:

- **Determinization:** N "worlds" per decision. In each, every hidden card gets a plausible card:
  - own deck = own deck list minus the cards already seen (shuffled);
  - opponent's hand, deck and secrets = cards of the opponent's class pool (the deck library of that
    class, or the arena tier list), minus cards already seen once too often;
  - a fresh random seed: random effects come out differently per world.
- The decision is the action with the best **average** over the worlds: probabilities count, the future
  is not known.

## Thinking (smarter than the built-in greedy bot)

- **Turn search:** in each world a beam search over whole sequences of the bot's own turn (width W,
  depth D, all legal actions incl. weapons, hero power, targets, choose-one/discover, minion positions).
- **Opponent's reply:** at the end of the bot's turn, the opponent's turn is simulated in that world
  (the engine's greedy bot plays the sampled hand) and the position is scored after it → trades,
  taunts, keeping the hero safe and not leaving threats alive matter.
- **Evaluation:** heroes (health + armor, more weight when low), minions (attack/health + keywords:
  taunt, divine shield, windfury, stealth, spell damage, frozen), weapons, cards in hand on both sides,
  secrets, lethal = ±1 000 000.
- **Mulligan:** keep cheap cards and the curve; replace expensive ones.
- Time limit per decision (well under the 75 s turn clock); a 0.6–1.5 s pause between actions.

## Pieces (bots/src)

| File | Job |
|---|---|
| `main.rs` | arguments (`--server --ladder 6 --arena 3 --admin 127.0.0.1:8098 --state-dir`), start bots and admin |
| `client.rs` | WebSocket session: register/login/resume (accounts in `<state-dir>/accounts.json`), the pack hash of Classic, send/receive |
| `brain.rs` | determinization, turn search, evaluation, mulligan |
| `arena.rs` | hero pick and card picks (bots/arena_tiers.json + curve) |
| `bot.rs` | the loop of one bot: ladder or arena, pauses, games, records, errors |
| `admin.rs` | 127.0.0.1 HTTP: `/` page, `/api/state` JSON |
| `cards.rs` | names (data/cards.json), deck library (bots/decks/*.json), class pools |

Data: `bots/decks/*.json` (≥ 3 validated decks per class), `bots/arena_tiers.json` (draft scores).

## Checks

- Unit tests: determinization keeps the known cards and fills only hidden ones; evaluation signs; search
  finds a lethal; mulligan; draft picks.
- An end-to-end run against a local server (other port, temp DB) with 2 ladder + 2 arena bots: games end,
  no refused actions, the admin page answers.
- Then the real run against `wss://hs.borovilov.xyz`.
