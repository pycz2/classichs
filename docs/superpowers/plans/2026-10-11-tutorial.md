# Обучение — план реализации

**Spec:** `docs/superpowers/specs/2026-10-11-tutorial-design.md`
**Исполнение:** inline (Native), один финальный ревьюер. Владелец заранее утвердил план.

## Global Constraints

- Godot 4.7.2, GDScript; строки интерфейса через `tr()`.
- Миссии собираются через `Scenario`; движок меняется только тегом `LOCKED` у силы героя.
- `CHANGELOG.md`; в конце версия `0.5.0`.

## Review Focus

1. Миссии 1–2: Джайна не может проиграть ни от урона, ни от Fatigue.
2. Конец хода в миссиях 1–3 запрещён только тогда, когда действительно есть что сыграть или чем атаковать; нет «зависания» (например, нет маны на единственную карту).
3. Сила героя недоступна в миссиях 1–4 ни в интерфейсе, ни в законных действиях, у обоих героев.
4. Победа сохраняет прогресс; перезапуск игры показывает пройденные миссии; поражение прогресс не меняет.
5. Каждая миссия проходима: бот за Джайну побеждает.

## Задачи

1. **`LOCKED`** у силы героя: движок, сценарий (`hero_power_locked`), стол прячет закрытую силу. Тесты.
2. **Карты обучения** (`cards/tutorial.gd`). Тесты.
3. **`Missions` + `Progress`**. Тесты: каждая миссия собирается, прогресс сохраняется.
4. **`Tutorial`** — контроллер: страховка Джайны, ограничения конца хода, подсказки, реплики. Тесты, включая прохождение каждой миссии ботом.
5. **UI**: `TutorialView`, баннер подсказки и проверка конца хода в столе, экран награды, пункт меню. Тесты.
6. **Проверка**: снимки экрана, `CHANGELOG`, версия `0.5.0`.
