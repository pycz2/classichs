# Игровой стол — план реализации

**Spec:** `docs/superpowers/specs/2026-10-11-table-design.md`
**Исполнение:** inline (Native), один финальный ревьюер. Владелец заранее утвердил план.

## Global Constraints

- Godot 4.7.2, GDScript. Движок (`engine/`, `cards/`) меняется только через новые функции с тестами.
- Строки интерфейса — английские через `tr()`.
- Логика без UI (`game/`) покрыта тестами в `tests/`. UI проверяется headless-сборкой сцен и снимками экрана web-сборки.
- `CHANGELOG.md` — запись в `[Unreleased]` на каждую задачу с поведением.

## Review Focus

1. Клик по карте, которую нельзя сыграть (нет маны, нет цели): ничего не ломается, подсказка не зависает.
2. Ход бота при полном столе, при пустой колоде, во время выбора (Tracking): бот не зацикливается и не делает незаконных действий.
3. Конец игры во время хода бота: таймер бота останавливается, оверлей показывается один раз.
4. Сценарий с ошибкой в отладочном столе: сообщение об ошибке, а не сбой.
5. Очень длинная история (300+ записей): панель прокручивается, все записи на месте.

## Задачи

1. **`GameState.clone()`** — тест: одинаковое действие → одинаковый хэш; клон независим.
2. **`Decks.basic()`** — тесты колод для 9 классов.
3. **`CardText`** — локализованное имя и текст, подстановка `$n`/`#n`, без тегов.
4. **`Bot`** — `value()`, `choose()`; тесты: летальная атака, законность, mulligan, выбор, 20 матчей бот против бота.
5. **`HistoryText`** — строки для всех типов событий; скрытие чужих карт.
6. **`Match`** — контроллер матча (люди/бот, задержка, сигналы); тесты без UI.
7. **UI-основа** — `ui/main.tscn`, `main.gd`, `palette.gd`, `menu.gd`, `training_setup.gd`; главная сцена проекта; `Cards.unload()` при выходе. Тест: сцена собирается headless.
8. **Отрисовка** — `card_view.gd`, `minion_view.gd`, `hero_view.gd`.
9. **Стол** — `match_view.gd`: раскладка, ввод (карта → вариант → позиция → цель; атака; сила героя), оверлеи mulligan/выбор/конец игры, подсказка, анимации, тряска. Тест: матч бот против бота через `MatchView` до конца.
10. **История** — `history_panel.gd` в столе. Тест: панель с 300+ записями.
11. **Отладочный стол** — `debug_table.gd` + «Позиция → JSON» в столе. Тест: пример загружается, ошибка показывается.
12. **Web-проверка** — экспорт, снимки экрана через headless Chrome (меню, стол в матче), исправление найденного; `CHANGELOG`, версия `0.2.0`.
