# Движок правил и данные карт — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Детерминированный движок правил Hearthstone (состояние июня 2014) на GDScript со всеми картами набора `VANILLA`, который проходит тесты в headless-режиме.

**Architecture:** Чистая логика на `RefCounted`-классах без дерева сцен. `GameState` хранит сущности, зоны, очередь триггеров и примитивы. `Game` наследует `GameState` и добавляет начало матча, ход, действия и их законность. Эффекты карт — словари хуков (`cards/*.gd`), которые меняют состояние только через примитивы.

**Tech Stack:** Godot 4.7.2 (GDScript), Python 3 для извлечения данных, HearthstoneJSON как источник данных.

**Spec:** `docs/superpowers/specs/2026-10-10-engine-design.md`

**Card checklist:** `docs/superpowers/plans/2026-10-10-cards-checklist.md` — все 500 сущностей (382 коллекционные карты, токены, силы героев, герои), разбитые по задачам 8–22.

## Global Constraints

- Godot 4.7.2, только GDScript. C# не используется.
- Все классы движка — `RefCounted`, не `Node`.
- Весь случайный выбор в движке идёт через `GameState.rng` (`RandomNumberGenerator`). `randi()`, `randf()`, `Array.shuffle()`, `Array.pick_random()` в `engine/` и `cards/` запрещены.
- В логике нет чисел с плавающей точкой. Числа из JSON сразу переводятся в `int`.
- Порядок обхода всегда явный: `play_order`, позиция на столе или `id`.
- Состояние правил — июнь 2014 (формат Classic). Спорное поведение: Hearthstone Wiki, затем Fireplace (`jleclanche/fireplace`).
- Хуки меняют состояние только через примитивы `GameState`.
- Каждая задача, которая меняет поведение, добавляет строку в `CHANGELOG.md` в раздел `## [Unreleased]`.
- Коммиты заканчиваются строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Тесты запускаются командой `./run_tests.sh` из корня репозитория. Фильтр: `./run_tests.sh -- <часть имени>`.

## Review Focus

1. **Числа из сети приходят как `float`.** `JSON.parse_string` превращает `5` в `5.0`, а `{"entity": 5} != {"entity": 5.0}`. Ожидание: `apply()` принимает действие после JSON и работает так же. Тест: `test_apply_accepts_json_roundtrip` в задаче 6.
2. **Незаконное действие не меняет состояние.** Ожидание: `apply()` возвращает `ok == false`, хэш состояния не меняется. Тест: `test_illegal_action_keeps_state` в задаче 6.
3. **Действие после конца игры.** Ожидание: после `game_over` любое действие отклоняется, `legal_actions()` пустой. Тест: `test_no_actions_after_game_over` в задаче 6.
4. **Бесконечная цепочка триггеров.** Ожидание: движок не зависает, а останавливает цепочку после лимита и пишет ошибку. Тест: `test_trigger_loop_is_bounded` в задаче 5.
5. **Ничья.** Оба героя умирают одновременно (например, Hellfire). Ожидание: `winner == -1`, `game_over == true`. Тест: `test_both_heroes_die_is_draw` в задаче 5.

- [ ] **Step 5: Создать `tests/run.gd`**

Раннер ловит ошибки скриптов через `Logger` (Godot 4.5+). Ошибка в тесте делает тест упавшим, даже если `check` не вызывался.

```gdscript
extends SceneTree


class ErrorCounter extends Logger:
	var count := 0
	var last := ""

	func _log_error(function: String, file: String, line: int, code: String, rationale: String,
			_editor_notify: bool, error_type: int, _script_backtrace: Array[ScriptBacktrace]) -> void:
		if error_type == ERROR_TYPE_WARNING:
			return
		count += 1
		last = "%s (%s:%d) %s" % [rationale if rationale != "" else code, file, line, function]


func _init() -> void:
	var args := OS.get_cmdline_user_args()
	var filter: String = args[0] if args.size() > 0 else ""
	var errors := ErrorCounter.new()
	OS.add_logger(errors)
	var files := Array(DirAccess.get_files_at("res://tests")).filter(
		func(f: String) -> bool: return f.begins_with("test_") and f.ends_with(".gd"))
	files.sort()
	var total := 0
	var failed := 0
	for f in files:
		var script: GDScript = load("res://tests/" + f)
		for m in script.get_script_method_list():
			var name: String = m.name
			if not name.begins_with("test_"):
				continue
			if filter != "" and not (f + ":" + name).contains(filter):
				continue
			total += 1
			var before := errors.count
			var t: TestCase = script.new()
			t.call(name)
			if errors.count > before:
				t.failures.append("script error: " + errors.last)
			if t.failures.is_empty():
				continue
			failed += 1
			print("FAIL %s:%s" % [f, name])
			for msg in t.failures:
				print("    " + msg)
	print("%d tests, %d failed" % [total, failed])
	quit(1 if failed > 0 or total == 0 else 0)
```

```python
#!/usr/bin/env python3
"""Download HearthstoneJSON and write data/cards.json.

Keeps: set == VANILLA (no enchantments, FX dummies, puzzles), all TU4* tutorial
cards, and EXTRA ids (heroes, The Coin, tokens that VANILLA references by their
original ids). Run from the repo root: python3 tools/extract_cards.py
"""
import json
import pathlib
import urllib.request

URL = "https://api.hearthstonejson.com/v1/latest/all/cards.json"
OUT = pathlib.Path(__file__).resolve().parent.parent / "data" / "cards.json"
FIELDS = ["id", "dbfId", "set", "type", "cardClass", "rarity", "cost", "attack", "health",
          "durability", "overload", "spellDamage", "race", "mechanics", "referencedTags",
          "collectible", "elite", "name", "text"]
EXTRA = [f"HERO_0{i}" for i in range(1, 10)] + """
EX1_323h EX1_323w EX1_383t GAME_005 CS2_013t EX1_317t EX1_131t EX1_625t EX1_625t2 EX1_014t
NEW1_040t ds1_whelptoken EX1_116t hexfrog EX1_025t EX1_534t EX1_538t EX1_160t
Mekka1 Mekka2 Mekka3 Mekka4 Mekka4t PRO_001a PRO_001b PRO_001at
""".split()
JUNK_PREFIXES = ("Story_", "VAN_DFX_", "VAN_GAME_")


def keep(c):
    if c["id"] in EXTRA:
        return True
    if c["id"].startswith("TU4"):
        return c["type"] != "ENCHANTMENT"
    return (c.get("set") == "VANILLA" and c["type"] != "ENCHANTMENT"
            and not c["id"].startswith(JUNK_PREFIXES))


def main():
    with urllib.request.urlopen(URL) as r:
        cards = json.load(r)
    out = [{k: c[k] for k in FIELDS if k in c} for c in cards if keep(c)]
    out.sort(key=lambda c: c["id"])
    missing = sorted(set(EXTRA) - {c["id"] for c in out})
    if missing:
        raise SystemExit(f"missing extra ids: {missing}")
    OUT.parent.mkdir(exist_ok=True)
    OUT.write_text(json.dumps(out, ensure_ascii=False, indent=0, sort_keys=True) + "\n")
    print(f"wrote {len(out)} cards to {OUT}")


if __name__ == "__main__":
    main()
```

Run: `python3 tools/extract_cards.py`
Expected: `wrote N cards to .../data/cards.json` без ошибки `missing extra ids`.

- [ ] **Step 4: Написать `engine/card_db.gd`**

```gdscript
class_name CardDb
extends RefCounted

const INT_FIELDS := ["dbfId", "cost", "attack", "health", "durability", "overload", "spellDamage"]

static var _cards: Dictionary = {}
static var _by_dbf: Dictionary = {}


static func _ensure_loaded() -> void:
	if not _cards.is_empty():
		return
	var text := FileAccess.get_file_as_string("res://data/cards.json")
	var list: Array = JSON.parse_string(text)
	for c: Dictionary in list:
		for k in INT_FIELDS:
			if c.has(k):
				c[k] = int(c[k])
		_cards[c.id] = c
		_by_dbf[c.dbfId] = c.id


static func card(id: String) -> Dictionary:
	_ensure_loaded()
	assert(_cards.has(id), "unknown card " + id)
	return _cards[id]


static func has(id: String) -> bool:
	_ensure_loaded()
	return _cards.has(id)


static func by_dbf(dbf: int) -> String:
	_ensure_loaded()
	return _by_dbf.get(dbf, "")


static func collectible() -> Array[String]:
	_ensure_loaded()
	var out: Array[String] = []
	for id: String in _cards:
		var c: Dictionary = _cards[id]
		if c.get("collectible", false) and c.get("set", "") == "VANILLA":
			out.append(id)
	out.sort()
	return out


static func define(id: String, c: Dictionary) -> void:
	_ensure_loaded()
	c["id"] = id
	_cards[id] = c
```

class_name Entity
extends RefCounted

## Keywords that come from card mechanics and that Silence removes.
const KEYWORDS := ["TAUNT", "CHARGE", "DIVINE_SHIELD", "STEALTH", "WINDFURY", "CANT_ATTACK",
	"ELUSIVE", "FROZEN", "IMMUNE", "FROZEN_THIS_TURN"]

var play_order := 0

var silenced := false


func _init(p_id: int, p_card_id: String, p_controller: int) -> void:
	id = p_id
	card_id = p_card_id
	controller = p_controller
	var c := card()
	for m: String in c.get("mechanics", []):
		if m in KEYWORDS:
			tags[m] = true
	if c.has("spellDamage"):
		tags["SPELLPOWER"] = c.spellDamage
	if c.type == "WEAPON":
		tags["DURABILITY"] = c.get("durability", 0)
	if c.type == "HERO":
		tags["ARMOR"] = 0


func card() -> Dictionary:
	return CardDb.card(card_id)


func type() -> String:
	return card().type


func is_minion() -> bool:
	return type() == "MINION"


func is_hero() -> bool:
	return type() == "HERO"


func is_weapon() -> bool:
	return type() == "WEAPON"


func race() -> String:
	return card().get("race", "")


func atk() -> int:
	var v: int = card().get("attack", 0)
	for e: Dictionary in enchantments:
		if e.has("set_atk"):
			v = e.set_atk
		v += e.get("atk", 0)
	return maxi(0, v + aura.atk)


func max_health() -> int:
	var v: int = card().get("health", 0)
	for e: Dictionary in enchantments:
		if e.has("set_hp"):
			v = e.set_hp
		v += e.get("hp", 0)
	return v + aura.hp


func health() -> int:
	return max_health() - damage


func has(tag: String) -> bool:
	return bool(tags.get(tag, false)) or bool(aura.tags.get(tag, false))


func spellpower() -> int:
	return int(tags.get("SPELLPOWER", 0)) + int(aura.tags.get("SPELLPOWER", 0))


func give_tag(tag: String, eot := false) -> void:
	tags[tag] = true
	if eot and not eot_tags.has(tag):
		eot_tags.append(tag)


func add_enchant(ench: Dictionary) -> void:
	enchantments.append(ench)


## Removes "this turn" enchantments and tags. A lost Health bonus never kills.
func remove_eot() -> void:
	var old_max := max_health()
	var old_hp := health()
	enchantments = enchantments.filter(func(e: Dictionary) -> bool: return not e.get("eot", false))
	for t in eot_tags:
		tags.erase(t)
	eot_tags.clear()
	fix_health(old_max, old_hp)


func silence() -> void:
	var old_max := max_health()
	var old_hp := health()
	enchantments.clear()
	eot_tags.clear()
	for k in KEYWORDS:
		tags.erase(k)
	tags.erase("SPELLPOWER")
	silenced = true
	fix_health(old_max, old_hp)


## When max Health drops, current Health becomes min(old current, new max).
func fix_health(old_max: int, old_health: int) -> void:
	var new_max := max_health()
	if new_max < old_max:
		damage = maxi(0, new_max - mini(old_health, new_max))


func snapshot() -> Dictionary:
	return {"card": card_id, "ctrl": controller, "zone": zone, "order": play_order,
		"dmg": damage, "tags": tags, "ench": enchantments, "eot": eot_tags, "sil": silenced}
```

class_name GameState
extends RefCounted
## Match state, event queue, death phase, auras and the primitives that card
## hooks use. Game (game.gd) adds turns, actions and legality on top.

const MAX_HAND := 10
const MAX_BOARD := 7
const MAX_MANA := 10
const MAX_QUEUE_STEPS := 5000
const HERO_POWERS := {
	"HERO_01": "VAN_HERO_01bp", "HERO_02": "VAN_HERO_02bp", "HERO_03": "VAN_HERO_03bp",
	"HERO_04": "VAN_HERO_04bp", "HERO_05": "VAN_HERO_05bp", "HERO_06": "VAN_HERO_06bp",
	"HERO_07": "VAN_HERO_07bp", "HERO_08": "VAN_HERO_08bp", "HERO_09": "VAN_HERO_09bp",
}

var rng := RandomNumberGenerator.new()
var players: Array[Player] = []
var entities: Dictionary = {}
var turn := 0
var current := 0
var phase := "MULLIGAN"
var pending: Dictionary = {}
var game_over := false
var winner := -1
var event_log: Array = []
## Full match history, never trimmed: [{"turn", "player", "action", "events"}].
## Entry 0 is {"action": {"type": "start"}} with the opening draws.
var history: Array = []
var queue: Array = []  # [Callable, Entity, Dictionary, bool needs_in_play]
var _next_id := 1
var _next_order := 1


func _init(p_seed: int) -> void:
	rng.seed = p_seed


func setup_players(hero0: String, hero1: String) -> void:
	for i in 2:
		var p := Player.new(i)
		var hero_id: String = [hero0, hero1][i]
		p.hero = new_entity(hero_id, i)
		_enter_play(p.hero)
		p.hero_power = new_entity(HERO_POWERS[hero_id], i)
		_enter_play(p.hero_power)
		players.append(p)


# --- entities -------------------------------------------------------------

func new_entity(card_id: String, controller: int) -> Entity:
	var e := Entity.new(_next_id, card_id, controller)
	entities[e.id] = e
	_next_id += 1
	return e


func ent(id: int) -> Entity:
	return entities.get(id)


func _enter_play(e: Entity) -> void:
	e.zone = "PLAY"
	e.play_order = _next_order
	_next_order += 1


func place_on_board(e: Entity, pos: int) -> void:
	var board := players[e.controller].board
	if pos < 0 or pos > board.size():
		pos = board.size()
	board.insert(pos, e)
	_enter_play(e)


func opponent(p: int) -> int:
	return 1 - p


func minions(p: int) -> Array[Entity]:
	return players[p].board.duplicate()


func all_minions() -> Array[Entity]:
	return _by_order(minions(0) + minions(1))


func chars(p: int) -> Array[Entity]:
	var out: Array[Entity] = [players[p].hero]
	out.append_array(players[p].board)
	return out


func all_chars() -> Array[Entity]:
	return _by_order(chars(0) + chars(1))


func adjacent(m: Entity) -> Array[Entity]:
	var out: Array[Entity] = []
	var board := players[m.controller].board
	var i := board.find(m)
	if i < 0:
		return out
	if i > 0:
		out.append(board[i - 1])
	if i < board.size() - 1:
		out.append(board[i + 1])
	return out


## All entities whose hooks can trigger: heroes, hero powers, weapons, minions, secrets.
func in_play() -> Array[Entity]:
	var out: Array[Entity] = []
	for p in players:
		out.append(p.hero)
		out.append(p.hero_power)
		if p.weapon:
			out.append(p.weapon)
		out.append_array(p.board)
		out.append_array(p.secrets)
	return _by_order(out)


func _by_order(arr: Array[Entity]) -> Array[Entity]:
	arr.sort_custom(func(a: Entity, b: Entity) -> bool: return a.play_order < b.play_order)
	return arr


func hooks_of(e: Entity) -> Dictionary:
	return {} if e.silenced else Cards.of(e.card_id)


# --- events and resolution --------------------------------------------------

func log_event(ev: Dictionary) -> void:
	event_log.append(ev)


## Logs the event and queues every matching "on" trigger (card and enchantment hooks).
func emit(ev: Dictionary) -> void:
	log_event(ev)
	for e in in_play():
		var h: Dictionary = hooks_of(e).get("on", {})
		if h.has(ev.type):
			queue.append([h[ev.type], e, ev, true])
		for ench: Dictionary in e.enchantments:
			if ench.has("hooks"):
				var eh: Dictionary = Cards.of(ench.hooks).get("on", {})
				if eh.has(ev.type):
					queue.append([eh[ev.type], e, ev, true])


## Calls matching "now" hooks at once. Used for replacement effects (Ice Block).
func emit_now(ev: Dictionary) -> void:
	for e in in_play():
		var h: Dictionary = hooks_of(e).get("now", {})
		if h.has(ev.type):
			h[ev.type].call(self, e, ev)


## Runs queued triggers, then the death phase, until nothing is left.
func resolve() -> void:
	var steps := 0
	while not game_over:
		while not queue.is_empty() and not game_over:
			steps += 1
			if steps > MAX_QUEUE_STEPS:
				push_warning("trigger chain stopped after %d steps" % MAX_QUEUE_STEPS)
				queue.clear()
				break
			var q: Array = queue.pop_front()
			var me: Entity = q[1]
			if q[3] and not (me.zone == "PLAY" or me.zone == "SECRET"):
				continue
			q[0].call(self, me, q[2])
		update_auras()
		if not _death_phase():
			break
	update_auras()


func _death_phase() -> bool:
	var dead: Array[Entity] = []
	for p in players:
		for m in p.board:
			if m.health() <= 0 or m.tags.get("TO_DESTROY", false):
				dead.append(m)
		if p.weapon and (int(p.weapon.tags.DURABILITY) <= 0 or p.weapon.tags.get("TO_DESTROY", false)):
			dead.append(p.weapon)
	_by_order(dead)
	for e in dead:
		var p := players[e.controller]
		if e.is_minion():
			e.tags["DIED_POS"] = p.board.find(e)
			p.board.erase(e)
		else:
			p.weapon = null
		e.zone = "GRAVEYARD"
	for e in dead:
		var h := hooks_of(e)
		if h.has("deathrattle"):
			queue.append([h.deathrattle, e, {}, false])
		emit({"type": "death", "entity": e.id, "player": e.controller, "card": e.card_id,
			"minion": e.is_minion()})
	var heroes_dead: Array[int] = []
	for p in players:
		if p.hero.health() <= 0:
			heroes_dead.append(p.index)
	if not heroes_dead.is_empty():
		game_over = true
		phase = "OVER"
		winner = -1 if heroes_dead.size() == 2 else opponent(heroes_dead[0])
		queue.clear()
		log_event({"type": "game_over", "winner": winner})
		return false
	return not dead.is_empty()


func update_auras() -> void:
	var all := in_play()
	var before := {}
	for e in all:
		before[e.id] = [e.max_health(), e.health()]
		e.aura = {"atk": 0, "hp": 0, "tags": {}}
	for e in all:
		var h := hooks_of(e)
		if h.has("aura") and e.zone == "PLAY":
			h.aura.call(self, e)
	for e in all:
		e.fix_health(before[e.id][0], before[e.id][1])


func aura_add(t: Entity, atk: int, hp: int, tags := {}) -> void:
	t.aura.atk += atk
	t.aura.hp += hp
	for k in tags:
		if k == "SPELLPOWER":
			t.aura.tags[k] = int(t.aura.tags.get(k, 0)) + int(tags[k])
		else:
			t.aura.tags[k] = tags[k]


# --- primitives -------------------------------------------------------------

func _id(e: Entity) -> int:
	return e.id if e else -1


func damage(src: Entity, t: Entity, amount: int) -> int:
	if t == null or t.zone != "PLAY" or amount <= 0:
		return 0
	var pre := {"type": "predamage", "source": _id(src), "target": t.id, "amount": amount}
	emit_now(pre)
	amount = pre.amount
	if amount <= 0 or t.has("IMMUNE"):
		return 0
	if t.has("DIVINE_SHIELD"):
		t.tags.erase("DIVINE_SHIELD")
		log_event({"type": "divine_shield_lost", "target": t.id})
		return 0
	if t.is_hero():
		var absorbed := mini(int(t.tags.ARMOR), amount)
		t.tags.ARMOR -= absorbed
		amount -= absorbed
		if amount <= 0:
			log_event({"type": "armor_lost", "target": t.id, "amount": absorbed})
			return 0
	t.damage += amount
	if src and src.is_minion() and src.has("STEALTH"):
		src.tags.erase("STEALTH")
	emit({"type": "damage", "source": _id(src), "target": t.id, "amount": amount,
		"player": t.controller})
	return amount


func heal(src: Entity, t: Entity, amount: int) -> int:
	if t == null or t.zone != "PLAY" or amount <= 0:
		return 0
	if src and players[src.controller].hero.has("HEAL_IS_DAMAGE"):
		return damage(src, t, amount)
	var healed := mini(amount, t.damage)
	if healed <= 0:
		return 0
	t.damage -= healed
	emit({"type": "heal", "source": _id(src), "target": t.id, "amount": healed})
	return healed

	return e


func draw(p: int, count := 1) -> Array[Entity]:
	var out: Array[Entity] = []
	var pl := players[p]
	for i in count:
		if pl.deck.is_empty():
			pl.fatigue += 1
			log_event({"type": "fatigue", "player": p, "amount": pl.fatigue})
			damage(null, pl.hero, pl.fatigue)
			continue
		var e: Entity = pl.deck.pop_back()
		if pl.hand.size() >= MAX_HAND:
			e.zone = "GRAVEYARD"
			log_event({"type": "burn", "player": p, "entity": e.id, "card": e.card_id})
			continue
		e.zone = "HAND"
		pl.hand.append(e)
		out.append(e)
		emit({"type": "draw", "player": p, "entity": e.id, "card": e.card_id})
	return out

func shuffle(arr: Array) -> void:
	for i in range(arr.size() - 1, 0, -1):
		var j := rng.randi_range(0, i)
		var tmp = arr[i]
		arr[i] = arr[j]
		arr[j] = tmp


func _spec_ok(src: Entity, spec: Variant, t: Entity) -> bool:
	if spec is Array:
		for s in spec:
			if not _spec_ok(src, s, t):
				return false
		return true
	if spec is Callable:
		return spec.call(self, src, t)
	var mine := t.controller == src.controller
	match spec:
		T.ANY: return true
		T.MINION: return t.is_minion()
		T.ENEMY_MINION: return t.is_minion() and not mine
		T.FRIENDLY_MINION: return t.is_minion() and mine
		T.ENEMY_CHAR: return not mine
		T.FRIENDLY_CHAR: return mine
		T.ENEMY_HERO: return t.is_hero() and not mine
	push_error("unknown target spec %s" % spec)
	return false


## Characters that src may target. Enemy Stealth is never targetable;

func targets(src: Entity, spec: Variant, is_spell := false) -> Array[Entity]:

	for t in all_chars():
		if t.controller != src.controller and t.has("STEALTH"):
			continue
		if is_spell and t.has("ELUSIVE"):
			continue
		if _spec_ok(src, spec, t):
			out.append(t)
	return out

func _mod_applies(mod: Dictionary, e: Entity) -> bool:
	match mod.kind:
		"any": return true
		"minion": return e.is_minion()
		"spell": return e.type() == "SPELL"
		"secret": return e.type() == "SPELL" and e.card().get("mechanics", []).has("SECRET")
	return false


func cost(e: Entity) -> int:
	var c: int = e.card().get("cost", 0)
	var h := Cards.of(e.card_id)
	if h.has("cost_mod"):
		c += h.cost_mod.call(self, e)
	for src in in_play():
		var sh := hooks_of(src)
		if sh.has("cost_aura") and src.zone == "PLAY":
			c = sh.cost_aura.call(self, src, e, c)
	for mod: Dictionary in players[e.controller].cost_mods:
		if _mod_applies(mod, e):
			c = mod.set if mod.has("set") else c + mod.delta
	return maxi(0, c)


## Removes "until": "use" mods that applied to e (called when e is played).
func consume_cost_mods(e: Entity) -> void:
	var pl := players[e.controller]
	pl.cost_mods = pl.cost_mods.filter(
		func(m: Dictionary) -> bool: return not (m.until == "use" and _mod_applies(m, e)))

func hero_atk(hero: Entity) -> int:

	var w := players[hero.controller].weapon
	if w and hero.controller == current:
		v += w.atk()
	return v


func attack_value(e: Entity) -> int:
	return hero_atk(e) if e.is_hero() else e.atk()

func to_dict() -> Dictionary:
	var ents := {}
	for id: int in entities:
		ents[str(id)] = entities[id].snapshot()
	var ps := []
	for p in players:
		ps.append(p.snapshot())
	return {"turn": turn, "current": current, "phase": phase, "rng": str(rng.state),
		"next_id": _next_id, "next_order": _next_order, "pending": pending,

func state_hash() -> String:
	var ctx := HashingContext.new()
	ctx.start(HashingContext.HASH_SHA256)
	ctx.update(JSON.stringify(to_dict()).to_utf8_buffer())
	return ctx.finish().hex_encode()

class_name Game
extends GameState
## Match setup, turns, actions and legality.

const COIN := "GAME_005"


func _init(p0: Dictionary, p1: Dictionary, p_seed: int, first := -1) -> void:
	super(p_seed)
	setup_players(p0.hero, p1.hero)
	for i in 2:
		var deck: Array = [p0, p1][i].deck
		for card_id: String in deck:
			var e := new_entity(card_id, i)
			e.zone = "DECK"
			players[i].deck.append(e)
		shuffle(players[i].deck)
	current = first if first >= 0 else rng.randi_range(0, 1)
	draw(current, 3)
	draw(opponent(current), 4)
	history.append({"turn": 0, "player": current, "action": {"type": "start"}, "events": event_log})
	event_log = []


# --- apply ------------------------------------------------------------------

## Applies one action. Illegal actions change nothing.
func apply(action: Dictionary) -> Dictionary:
	var a := _normalize(action)
	if not legal_actions().has(a):
		return {"ok": false, "error": "illegal action %s" % JSON.stringify(a), "events": []}
	event_log = []
	var who := current
	match a.type:
		"mulligan": _do_mulligan(a.player, a.replace)
		"end_turn": _end_turn()
		"concede": _concede(a.player)
		_: _apply_play_action(a)
	resolve()
	history.append({"turn": turn, "player": a.get("player", who), "action": a, "events": event_log})
	return {"ok": true, "error": "", "events": event_log}


## Converts JSON floats to ints and sorts mulligan ids, so equality checks work.
func _normalize(action: Dictionary) -> Dictionary:
	var a := {}
	for k: String in action:
		var v = action[k]
		if v is float:
			v = int(v)
		elif k == "replace":
			var ids: Array = []
			for x in v:
				ids.append(int(x))
			ids.sort()
			v = ids
		a[k] = v
	return a


## Hook point for task 6 (play, attack, hero_power, choose).
func _apply_play_action(_a: Dictionary) -> void:
	pass


func legal_actions() -> Array:
	var out := []
	if game_over:
		return out
	if phase == "MULLIGAN":
		for p in players:
			if not p.mulliganed:
				for ids in _subsets(p.ids(p.hand)):
					out.append({"type": "mulligan", "player": p.index, "replace": ids})
		return out
	out.append({"type": "end_turn", "player": current})
	out.append({"type": "concede", "player": current})
	_legal_play_actions(out)
	return out


## Hook point for task 6.
func _legal_play_actions(_out: Array) -> void:
	pass


func _subsets(ids: Array[int]) -> Array:
	var out := []
	for mask in 1 << ids.size():
		var s: Array = []
		for i in ids.size():
			if mask & (1 << i):
				s.append(ids[i])
		s.sort()
		out.append(s)
	return out


# --- mulligan and turns -----------------------------------------------------

func _do_mulligan(p: int, replace: Array) -> void:
	var pl := players[p]
	var old: Array[Entity] = []
	for id: int in replace:
		var e := ent(id)
		pl.hand.erase(e)
		old.append(e)
	draw(p, old.size())
	for e in old:
		e.zone = "DECK"
		pl.deck.append(e)
	shuffle(pl.deck)
	pl.mulliganed = true
	log_event({"type": "mulligan", "player": p, "count": old.size()})
	if players[0].mulliganed and players[1].mulliganed:
		_finish_mulligan()


func _finish_mulligan() -> void:
	add_to_hand(opponent(current), COIN)
	phase = "PLAY"
	_start_turn()


func _start_turn() -> void:
	var p := players[current]
	turn += 1
	p.max_mana = mini(MAX_MANA, p.max_mana + 1)
	p.overload_locked = p.overload_owed
	p.overload_owed = 0
	p.mana = maxi(0, p.max_mana - p.overload_locked)
	p.cards_played_this_turn = 0
	p.minions_played_this_turn = 0
	p.hero_power.tags.erase("USED")
	for c in chars(current):
		c.tags.erase("EXHAUSTED")
		c.tags["ATTACKS"] = 0
	log_event({"type": "turn_start", "player": current, "turn": turn})
	emit({"type": "turn_start", "player": current})
	resolve()
	if not game_over:
		draw(current)


func _end_turn() -> void:
	emit({"type": "turn_end", "player": current})
	resolve()
	if game_over:
		return
	for e in in_play():
		e.remove_eot()
	for pl in players:
		pl.cost_mods = pl.cost_mods.filter(func(m: Dictionary) -> bool: return m.turn > turn)
	for c in chars(current):
		if c.has("FROZEN") and not (c.tags.get("FROZEN_THIS_TURN", false) and int(c.tags.get("ATTACKS", 0)) > 0):
			c.tags.erase("FROZEN")
		c.tags.erase("FROZEN_THIS_TURN")
	log_event({"type": "turn_end", "player": current})
	current = opponent(current)
	_start_turn()


func _concede(p: int) -> void:
	game_over = true
	phase = "OVER"
	winner = opponent(p)
	log_event({"type": "game_over", "winner": winner})
```

Правило `cost_mods`: каждый мод исчезает в конце хода с номером `mod.turn`. `add_cost_mod` ставит `turn` равным текущему ходу, поэтому Kirin Tor Mage и Preparation действуют только в этот ход. Мод с `"until": "use"` дополнительно исчезает, когда карта, к которой он применился, разыграна. Millhouse Manastorm (задача 13) кладёт мод сопернику с `"turn": turn + 1` напрямую в `players[p].cost_mods`: мод переживает текущий ход и исчезает в конце следующего.

	var p := players[e.controller]
	if e.is_minion() and p.board.size() >= MAX_BOARD:
		return false
	if e.card().get("mechanics", []).has("SECRET"):
		for s in p.secrets:
			if s.card_id == e.card_id:
				return false
	var h := Cards.of(e.card_id)

	return players[e.controller].cards_played_this_turn > 0

func _play_targets(e: Entity, choice: int) -> Array:

	var spec: Variant = h.get("target")

		spec = Cards.of(h.choose_one[choice]).get("target")
	if h.has("combo_target"):
		spec = h.combo_target if _combo_active(e) else null
	var is_spell := e.type() == "SPELL"
	return _spec_targets(e, spec, is_spell, not is_spell)


func _spec_targets(e: Entity, spec: Variant, is_spell: bool, optional: bool) -> Array:
	if spec == null:
		return [-1]
	var ids: Array = []
	for t in targets(e, spec, is_spell):
		ids.append(t.id)
	if ids.is_empty() and optional:
		return [-1]
	return ids

	if not e.is_minion():
		return [-1]

func _can_attack(a: Entity) -> bool:
	if attack_value(a) <= 0 or a.has("FROZEN") or a.has("CANT_ATTACK"):
		return false

func _do_play(e: Entity, t: Entity, pos: int, choice: int) -> void:
	var p := players[e.controller]
	p.mana -= cost(e)
	consume_cost_mods(e)
	p.hand.erase(e)
	var combo := _combo_active(e)
	p.cards_played_this_turn += 1
	p.overload_owed += int(e.card().get("overload", 0))
	match e.type():
		"MINION": _play_minion(e, t, pos, choice, combo)
		"SPELL": _play_spell(e, t, choice, combo)
		"WEAPON": _play_weapon(e, t, combo)


func _run_effect(e: Entity, key: String, t: Entity, choice: int, combo: bool) -> void:
	var h := Cards.of(e.card_id)
	if choice >= 0:
		Cards.of(h.choose_one[choice]).effect.call(self, e, t)
	elif combo and h.has("combo"):
		h.combo.call(self, e, t)
	elif h.has(key):
		h[key].call(self, e, t)


func _play_minion(e: Entity, t: Entity, pos: int, choice: int, combo: bool) -> void:
	players[e.controller].minions_played_this_turn += 1
	place_on_board(e, pos)
	e.give_tag("EXHAUSTED")
	emit({"type": "play", "entity": e.id, "player": e.controller, "kind": "minion",
		"target": t.id if t else -1, "card": e.card_id})
	emit({"type": "summon", "entity": e.id, "player": e.controller, "card": e.card_id})
	resolve()
	if game_over or e.zone != "PLAY":
		return
	if t and t.zone != "PLAY":
		t = null
	_run_effect(e, "battlecry", t, choice, combo)
	resolve()
	if game_over or e.zone != "PLAY":
		return
	emit({"type": "after_summon", "entity": e.id, "player": e.controller, "card": e.card_id})


func _play_spell(e: Entity, t: Entity, choice: int, combo: bool) -> void:
	if e.card().get("mechanics", []).has("SECRET"):
		players[e.controller].secrets.append(e)
		_enter_play(e)
		e.zone = "SECRET"
		emit({"type": "play", "entity": e.id, "player": e.controller, "kind": "secret",
			"target": -1, "card": e.card_id})
		return
	e.zone = "SETASIDE"
	var ev := {"type": "play", "entity": e.id, "player": e.controller, "kind": "spell",
		"target": t.id if t else -1, "card": e.card_id, "countered": false}
	emit(ev)
	resolve()
	if game_over:
		return
	if not ev.countered:
		var nt: Entity = ent(ev.target) if ev.target >= 0 else null
		if nt == null or nt.zone == "PLAY":
			_run_effect(e, "spell", nt, choice, combo)
			resolve()
	e.zone = "GRAVEYARD"
	if not game_over:
		emit({"type": "after_spell", "entity": e.id, "player": e.controller, "card": e.card_id})


func _play_weapon(e: Entity, t: Entity, combo: bool) -> void:
	emit({"type": "play", "entity": e.id, "player": e.controller, "kind": "weapon",
		"target": t.id if t else -1, "card": e.card_id})
	resolve()
	if game_over:
		return
	_run_effect(e, "battlecry", t, -1, combo)
	resolve()
	if not game_over:
		equip_entity(e)

func _do_attack(a: Entity, d: Entity) -> void:
	a.tags["ATTACKS"] = int(a.tags.get("ATTACKS", 0)) + 1
	a.tags.erase("STEALTH")
	var ev := {"type": "attack", "attacker": a.id, "defender": d.id, "player": a.controller}
	emit(ev)
	resolve()
	if game_over or a.zone != "PLAY" or a.controller != current:
		return
	d = ent(ev.defender)
	if d == null or d.zone != "PLAY":
		return
	var weapon := players[a.controller].weapon if a.is_hero() else null
	var immune := weapon != null and Cards.of(weapon.card_id).get("immune_while_attacking", false)
	if immune:
		a.give_tag("IMMUNE")
	var a_dmg := attack_value(a)
	var d_dmg := attack_value(d)
	damage(a, d, a_dmg)
	damage(d, a, d_dmg)
	if immune:
		a.tags.erase("IMMUNE")
	if weapon and weapon.zone == "PLAY":
		var wh := Cards.of(weapon.card_id)
		if not wh.has("durability_on_attack") or wh.durability_on_attack.call(self, weapon, d):
			weapon.tags.DURABILITY = int(weapon.tags.DURABILITY) - 1
	emit({"type": "after_attack", "attacker": a.id, "defender": d.id, "player": a.controller})


# --- hero power and choice --------------------------------------------------

func _do_hero_power(t: Entity) -> void:
	var p := players[current]
	var hp := p.hero_power
	p.mana -= cost(hp)
	hp.give_tag("USED")
	Cards.of(hp.card_id).hero_power.call(self, hp, t)
	emit({"type": "hero_power", "player": current, "entity": hp.id, "target": t.id if t else -1})


func _do_choose(option: Entity) -> void:
	var src := ent(pending.source)
	pending = {}
	Cards.of(src.card_id).on_choose.call(self, src, option)

```gdscript
class_name Sim
extends RefCounted
## Random-play harness for tests. Uses its own RNG; the engine RNG stays separate.

const CLASSES := {"HERO_01": "WARRIOR", "HERO_02": "SHAMAN", "HERO_03": "ROGUE",
	"HERO_04": "PALADIN", "HERO_05": "HUNTER", "HERO_06": "DRUID", "HERO_07": "WARLOCK",
	"HERO_08": "MAGE", "HERO_09": "PRIEST"}


static func random_deck(rng: RandomNumberGenerator, card_class: String) -> Array:
	var pool: Array = CardDb.collectible().filter(func(id: String) -> bool:
		var c := CardDb.card(id)
		return c.cardClass == card_class or c.cardClass == "NEUTRAL")
	var deck: Array = []
	while deck.size() < 30:
		var id: String = pool[rng.randi_range(0, pool.size() - 1)]
		var limit := 1 if CardDb.card(id).get("rarity", "") == "LEGENDARY" else 2
		if deck.count(id) < limit:
			deck.append(id)
	return deck


static func play_random(seed: int, max_steps := 400) -> Dictionary:
	var rng := RandomNumberGenerator.new()
	rng.seed = seed
	var heroes := CLASSES.keys()
	var h0: String = heroes[rng.randi_range(0, 8)]
	var h1: String = heroes[rng.randi_range(0, 8)]
	var g := Game.new({"hero": h0, "deck": random_deck(rng, CLASSES[h0])},
		{"hero": h1, "deck": random_deck(rng, CLASSES[h1])}, seed)
	var actions := []
	var hashes := []
	for i in max_steps:
		var legal := g.legal_actions()
		if legal.is_empty():
			break
		# Prefer anything over end_turn/concede so games progress.
		var useful := legal.filter(func(a: Dictionary) -> bool: return a.type != "concede")
		if useful.size() > 1 and rng.randf() < 0.85:
			useful = useful.filter(func(a: Dictionary) -> bool: return a.type != "end_turn")
		var a: Dictionary = useful[rng.randi_range(0, useful.size() - 1)]
		var r := g.apply(a)
		assert(r.ok, r.error)
		actions.append(a)
		hashes.append(g.state_hash())
	return {"actions": actions, "hashes": hashes, "game": g}
```

- [ ] **Step 1: Написать `tests/test_coverage.gd`**

```gdscript
extends TestCase

const KEYWORDS := ["taunt", "charge", "divine shield", "stealth", "windfury"]
## Cards whose text needs no hook (rules elsewhere or unreachable in Classic).
const NO_HOOK := ["VAN_EX1_560"]  # Nozdormu: turn timer belongs to UI/network


static func _clean(t: String) -> String:
	var re := RegEx.create_from_string("<[^>]+>|\\[x\\]")
	return re.sub(t, "", true).strip_edges()


static func _keyword_only(c: Dictionary) -> bool:
	var text := _clean(c.get("text", {}).get("enUS", "")).to_lower().replace("\n", " ")
	for part in text.split(".", false):
		for p2 in part.split(",", false):
			var p := p2.strip_edges()
			if p == "" or KEYWORDS.has(p) or p.begins_with("spell damage +") or p.begins_with("overload: ("):
				continue
			return false
	return true


func test_every_collectible_card_with_effect_has_hook() -> void:
	var missing := []
	for id in CardDb.collectible():
		var c := CardDb.card(id)
		if _keyword_only(c) or NO_HOOK.has(id):
			continue
		if Cards.of(id).is_empty():
			missing.append("%s %s" % [id, c.name.enUS])
	eq(missing, [], "cards without hooks")


func test_every_hero_power_used_in_classic_has_hook() -> void:
	for id in GameState.HERO_POWERS.values() + ["VAN_EX1_tk33", "EX1_625t", "EX1_625t2"]:
		check(Cards.of(id).has("hero_power"), "hero power " + id)


func test_hooks_reference_known_cards() -> void:
	for id in Cards.all_ids():
		check(CardDb.has(id), "hook for unknown card " + str(id))
```
