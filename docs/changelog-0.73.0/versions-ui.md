ru: В библиотеке игр у игры с версиями видно, какая версия выбрана, и есть кнопка «Выбрать версию»: версии сгруппированы по эпохам, у каждой указаны дата и что изменилось. Выбранную версию показывают меню игры и заголовок лобби. Кнопка «Сравнить версии» показывает все карты, которые отличаются в двух версиях: слева карта как в первой, справа как во второй, изменённые части обведены красным. Ниже идут добавленные и убранные карты. Список можно отфильтровать по классу, по тому, что изменилось, и по названию.
en: In the games library a game with versions shows the version chosen and has "Choose a version": the versions are grouped by era, each with its date and what changed. The game's menu and the lobby header name the chosen version. "Compare versions" lists every card that differs between two versions: on the left as in the first, on the right as in the second, with the changed parts circled in red, then the cards added and removed. The list filters by class, by what changed and by name.
