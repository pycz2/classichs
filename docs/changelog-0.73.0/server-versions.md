## Русский

- Игра на сервере: на экране «Играть» можно выбрать версию игры и режим «Стандартный» или «Вольный», если у версии их два. У каждой версии и каждого режима свой рейтинг и свои соперники.

## English

- Server games: the Play screen lets you choose the game's version, and Standard or Wild when the version has both. Each version and mode has its own ladder and its own opponents.
