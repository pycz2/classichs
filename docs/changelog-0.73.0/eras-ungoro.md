ru: В «Hearthstone 2014–2019: все версии» появились четыре версии времён «Экспедиции в Ун'Горо», с апреля по июль 2017 года. Это выход дополнения, обновление 8.2.0 (у «Ловушки с дротиками» слова «сила героя» больше не жирные), 8.2.2 без изменений карт и 8.4.0. В 8.4.0 «Подземным пещерам» нужно уже пять существ с одинаковым названием, а Нефритовый дух, Джинн ветров, Пламя Аззинота, Мановая жеода, Кристалл и Халлазил Перерожденный стали элементалями.
en: "Hearthstone 2014–2019: every version" gets four Journey to Un'Goro versions, April to July 2017: the expansion's release, patch 8.2.0 (Dart Trap's "Hero Power" is no longer bold), 8.2.2 with no card changes, and 8.4.0, where The Caverns Below needs five minions with the same name and Jade Spirit, Djinni of Zephyrs, Flame of Azzinoth, Mana Geode, Crystal and Hallazeal the Ascended become Elementals.
