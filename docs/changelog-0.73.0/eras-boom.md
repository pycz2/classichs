ru: В «Hearthstone 2014–2019» добавлены четыре версии времён «Проекта Бумного дня» (август–ноябрь 2018): выход дополнения, обновление 12.2 с ключевым словом «При взятии» и исправлением Гигантов джунглей (Тьма больше не засчитывается), ослабление Озорной изобретательницы, Маназмея и Авианы и обновление 12.4 с четырьмя новыми классическими картами: Сосулькой, Томом интеллекта, Зовом пустоты и Кражей.
en: "Hearthstone 2014–2019" gets four versions from The Boomsday Project days (August to November 2018): the expansion's release, patch 12.2 with the "Casts When Drawn" keyword and the Jungle Giants fix (The Darkness no longer counts), the Giggling Inventor, Mana Wyrm and Aviana nerfs, and patch 12.4 with four new Classic cards: Icicle, Tome of Intellect, Call of the Void and Pilfer.
