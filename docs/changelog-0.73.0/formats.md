- Форматы «Стандартный» и «Вольный» в «Hearthstone 2014–2019»: тренировку можно начать в любом из них, в стандартной игре случайные карты только стандартные, вольные колоды помечены, в редакторе колод есть фильтр по формату. Арена каждой версии берёт карты и запреты своего времени. У каждой версии свои колоды с HearthPwn.
- Standard and Wild in Hearthstone 2014–2019: Training starts in either, a Standard game makes only Standard random cards, Wild decks are marked, the deck builder filters by format. Each version's Arena drafts the cards and bans of its time. Every version has its own HearthPwn decks.
