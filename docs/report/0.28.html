Разделы

Проверка подписи Android

Локальная страница, которая проверяет три секрета GitHub так же, как CI, и говорит, что именно не так.

python3 tools/android_keystore_check.py     # откроет страницу в браузере
Проверяет по шагам
  • base64 корректен и не закодирован дважды
  • это хранилище ключей (JKS или PKCS12)
  • пароль открывает хранилище
  • есть ключ с таким alias (с учётом регистра)
  • это закрытый ключ
  • пароль ключа равен паролю хранилища
Умеет
  • на каждую ошибку — как её исправить
  • создать новое хранилище PKCS12 и сразу дать три значения для GitHub
  • работает только на этом компьютере; секреты не пишутся ни в лог, ни на диск

CI тоже стал умнее: если секреты не открывают ключ, сборка не падает, а пишет понятное предупреждение и подписывает APK одноразовым ключом.

Что внутри .cardpack

Обычный zip. Щёлкните строку, чтобы прочитать, зачем этот файл.

Выберите файл слева.

Два хэша

rules_hash — от правил, карт, миссий и скриптов (всё, что влияет на игру). Игроки с одинаковым rules_hash играют вместе, даже если у них разный арт.
content_hash — от содержимого всех файлов. По нему пакет хранится, скачивается и проверяется после передачи.
python3 tools/pack.py build packs/neon -o build/packs/neon.cardpack
python3 tools/pack.py check build/packs/neon.cardpack     # 0 ошибок, 0 предупреждений
python3 tools/pack.py hash  build/packs/neon.cardpack

Документация: docs/packs/format.md, rules.md, cards.md, api.md, lua.md, fx.md, схемы в docs/packs/schema/.

Логика карт на маленьком Lua

Свой интерпретатор подмножества Lua на Rust (rust/script): без зависимостей и без unsafe, работает и в браузере.

Можно
  • переменные, функции, замыкания, таблицы, циклы
  • библиотека table, string, math, list
  • API движка g.*: урон, лечение, призыв, добор, усиления, события, случайность через ГСЧ партии
Нельзя
  • файлы, сеть, время, load, require, os, io
  • метатаблицы, корутины, дробные числа
  • больше 200 000 шагов, 200 вызовов вглубь, 10 000 элементов в таблице — ошибка карты, а не зависание
cards.VAN_CS2_032 = {
  spell = function(g, me)
    lib.each_enemy_minion(g, me, 4)   -- 4 урона каждому существу противника
  end,
}
-- Root Access: take control of a random enemy minion; the opponent draws 2.
cards.root_access = {
  can_play = function(g, me) return #g.minions(g.enemy(me)) > 0 end,
  spell = function(g, me)
    local p = g.ctrl(me)
    g.take_control(lib.random_enemy_minion(g, me), p)
    g.draw(g.opponent(p), 2)
  end,
}

Скорость

Вызов небольшого хука: ~80 нс нативно, ~120 нс в WebAssembly
Заклинание «урон всем существам» (цикл + 3 удара): ~1 мкс нативно, ~1,2 мкс в WebAssembly
Полная проверка 7833 партий: 79 с до переноса на Lua, ~80–90 с после.

Перенос Classic на Lua

Все хуки карт переписаны с Rust на Lua. Каждый шаг проверялся на 7833 записанных партиях прежнего движка: 323 838 шагов, 142 694 выбора бота, 0 расхождений.

Шесть агентов переносили классы параллельно, каждый в своей копии репозитория. Потом ветки слились, общие файлы объединились скриптом, и последний шаг (B3) убрал из движка весь старый механизм Rust-хуков и все константы Hearthstone: «Монетку», 30 здоровья, 10 маны, классы, редкости, английские тексты.

Neonfall — новая игра

Веспер-Арк, затопленный мегаполис на сваях, где дождь не кончается никогда. Корпорации наверху, банды внизу, призраки в Решётке. Всё придумано с нуля.

Свои названия механик

Баланс (тысячи партий бот против бота)

Чтобы первый ход не давал перевеса, правила пакета дают второму игроку 5 карт, а боту — настройки bot.trap и bot.depth, чтобы он играл «Протоколы» и «Jumpstart». Classic это не затрагивает.

Каждый пакет со своим лицом

Пакет может принести тему интерфейса (ui/theme.json): цвета, кнопки, панели, свечение, шрифты, частицы в меню. Classic выглядит ровно как раньше (проверено попиксельно), Neonfall — неоново. Смена — сразу, без перезапуска.

Сервер раздаёт игры

Пакеты хранятся в S3 (SeaweedFS в Docker) или в папке. Neonfall — игра сервера по умолчанию, Classic тоже есть.

Админ / игрок
Сервер
Хранилище S3
Загрузка .cardpack (админ — для всех, игрок — свой, до 100 МБ и 10 штук)
Полная проверка: лимиты формата, правила, компиляция всех скриптов, пробная партия ботов, где пробуется каждый разрешённый ход
Хранение по content_hash; событие в журнале админки
Игрок видит пакеты сервера, скачивает (с проверкой хэша) и кэширует
Очередь queue {mode, deck, pack}: своя для каждой игры; таймеры, ранги и арена — из правил пакета
Дружеская игра на своём пакете: друг видит «Скачать и играть» с размером

Несколько серверов

Ранги по играм
У каждой игры свой ладдер; ранги хранятся по id пакета и сезону, поэтому новая версия пакета их не сбрасывает.

cargo run --release -- --packs-dir ../packs
