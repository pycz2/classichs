## Русский

- Классика открывается экраном «Версии игры»: версии сгруппированы по эпохам, у каждой дата и что изменилось. Кнопка «Играть в этой версии» открывает выбранную версию как отдельную игру со своим меню, режимами, колодами и видом. Внутри версии переключиться на другую нельзя: «Покинуть игру» возвращает к списку версий. Там же есть «Сравнить версии» для любых двух. На сервере выбор устроен так же.
- Колоды хранятся отдельно для каждой версии. Ваши прежние колоды Классики один раз копируются в версию мая 2014 года, старый файл остаётся.

## English

- Classic opens on the Versions screen: the versions by era, each with its date and what changed. "Play this version" enters the chosen one as a game of its own, with its menu, modes, decks and look. There is no switching to another version inside: "Leave the game" goes back to the Versions. "Compare versions" there compares any two. A server's games work the same way.
- Decks are kept per version. Your old Classic decks are copied once into the May 2014 version; the old file stays.
