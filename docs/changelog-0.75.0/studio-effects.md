## Русский

- ClassicHS Studio: эффект карты собирается из блоков «когда, на кого, что сделать». Есть боевой клич, предсмертный хрип, серия приёмов, секреты, ауры, начало и конец хода, атака и получение урона. Действий 19: урон, лечение, добор карт, призыв, усиление, заморозка, превращение, раскопка и другие. По блокам студия сама пишет Lua-скрипт карты и предлагает текст карты на английском. Скрипт можно открыть и дописать вручную.

## English

- ClassicHS Studio: a card's effect is built from blocks of "when, on whom, what to do": Battlecry, Deathrattle, Combo, Secrets, auras, the start and end of the turn, attacking and taking damage, with 19 actions such as damage, healing, drawing cards, summoning, buffs, Freeze, Transform and Discover. The Studio writes the card's Lua script from the blocks and suggests the card's English text; you can open the script and edit it by hand.
