- ClassicHS Studio — редактор карт, отдельное приложение для компьютера и браузера. Можно создать свою игру или открыть копию установленного пакета. Во вкладках задаются названия на 8 языках, основные правила, картинки для библиотеки и меню, классы с героями и силами героя, наборы, редкости, расы и готовые колоды. Игру можно проверить ботами, сохранить в .cardpack, установить в игру, загрузить на сервер и попробовать в матче против бота. Изменения сохраняются сами.
- ClassicHS Studio, a card editor: a separate application for the desktop and the browser. Start a game of your own or open a copy of an installed pack. Its tabs set the names in 8 languages, the basic rules, the pictures for the library and the menu, the classes with their heroes and Hero Powers, the sets, rarities, tribes and ready decks. A game can be checked with bots, saved as a .cardpack, installed into the game, uploaded to a server and tried in a match against the bot. Changes save themselves.
